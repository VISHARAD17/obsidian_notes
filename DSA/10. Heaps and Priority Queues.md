### 128. Kth Largest Element in an Array — #215
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Min-heap of size K** — maintain a min-heap of K elements. When size exceeds K, poll minimum. Heap top = Kth largest. QuickSelect is O(n) average alternative.

`````col
````col-md
**Explanation:**
1. Add elements to a min-heap
2. When heap size > K → poll (remove smallest)
3. After processing all elements, heap top = Kth largest
4. Alternatively: QuickSelect with random pivot for O(n) avg
````

````col-md
**Code:**
```java
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();
    for (int num : nums) {
        minHeap.offer(num);
        if (minHeap.size() > k) minHeap.poll();
    }
    return minHeap.peek();
}
```
````
`````

**Complexity:** Time: O(n log k) | Space: O(k)

**Edge Cases:**
- k = 1 → max element
- k = n → min element
- Duplicates → all treated as separate elements

### 129. K Closest Points to Origin — #973
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Max-heap of size K with custom comparator** — keep K smallest distances. When heap exceeds K, remove the max (farthest). Max-heap inverts comparison.

`````col
````col-md
**Explanation:**
1. Max-heap ordered by distance (largest on top)
2. For each point: add to heap
3. If size > K → poll (remove farthest)
4. Remaining K points are closest
````

````col-md
**Code:**
```java
public int[][] kClosest(int[][] points, int k) {
    PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
        (a, b) -> (b[0]*b[0] + b[1]*b[1]) - (a[0]*a[0] + a[1]*a[1]));
    for (int[] p : points) {
        maxHeap.offer(p);
        if (maxHeap.size() > k) maxHeap.poll();
    }
    return maxHeap.toArray(new int[k][]);
}
```
````
`````

**Complexity:** Time: O(n log k) | Space: O(k)

**Edge Cases:**
- k = n → return all points
- Multiple points at same distance → any k of them
- No need to actually compute sqrt (compare squared distances)

### 130. Top K Frequent Words — #692
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Min-heap with composite comparator (freq asc, alpha desc)** — min-heap of size K. Comparator: lower freq first; same freq → reverse alphabetical first (so correct ones survive).

`````col
````col-md
**Explanation:**
1. Count word frequencies with HashMap
2. Min-heap with comparator: compare by freq ascending; if tie, by word descending
3. Add all words; poll when size > K
4. Extract remaining K words, reverse for final order
````

````col-md
**Code:**
```java
public List<String> topKFrequent(String[] words, int k) {
    Map<String, Integer> freq = new HashMap<>();
    for (String w : words) freq.merge(w, 1, Integer::sum);

    PriorityQueue<String> pq = new PriorityQueue<>(
        (a, b) -> freq.get(a).equals(freq.get(b))
            ? b.compareTo(a) : freq.get(a) - freq.get(b));

    for (String w : freq.keySet()) {
        pq.offer(w);
        if (pq.size() > k) pq.poll();
    }

    LinkedList<String> result = new LinkedList<>();
    while (!pq.isEmpty()) result.addFirst(pq.poll());
    return result;
}
```
````
`````

**Complexity:** Time: O(n log k) | Space: O(n)

**Edge Cases:**
- All words same frequency → sorted alphabetically
- k = total unique words → all words sorted

### 131. Find Median from Data Stream — #295
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Two heaps — max-heap (lower half) + min-heap (upper half)** — balance heaps so sizes differ by ≤ 1. Median = top of larger heap or average of both tops.

`````col
````col-md
**Explanation:**
1. `maxHeap` stores lower half (max on top)
2. `minHeap` stores upper half (min on top)
3. Add to maxHeap first, then move maxHeap top to minHeap
4. Balance: if minHeap larger, move back
5. Median: if sizes equal → avg of tops; else maxHeap top
````

````col-md
**Code:**
```java
class MedianFinder {
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    public void addNum(int num) {
        maxHeap.offer(num);
        minHeap.offer(maxHeap.poll());
        if (minHeap.size() > maxHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        if (maxHeap.size() > minHeap.size()) return maxHeap.peek();
        return (maxHeap.peek() + minHeap.peek()) / 2.0;
    }
}
```
````
`````

**Complexity:** Time: O(log n) per add, O(1) median | Space: O(n)

**Edge Cases:**
- Single element → that element
- Two elements → average
- Stream of duplicates → both heaps have same value

### 132. Task Scheduler — #621
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Greedy + max-heap (most frequent task first)** — always schedule the most frequent remaining task. Cooldown handled by a waiting queue with release times.

`````col
````col-md
**Explanation:**
1. Count frequencies, add to max-heap
2. Each time unit: poll most frequent, decrement, put in cooldown queue with ready time
3. If cooldown item is ready → add back to heap
4. If heap empty and queue not empty → idle
5. Count total time units
````

````col-md
**Code:**
```java
public int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char t : tasks) freq[t - 'A']++;
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
    for (int f : freq) if (f > 0) maxHeap.offer(f);

    Queue<int[]> cooldown = new LinkedList<>(); // [count, readyTime]
    int time = 0;
    while (!maxHeap.isEmpty() || !cooldown.isEmpty()) {
        time++;
        if (!maxHeap.isEmpty()) {
            int count = maxHeap.poll() - 1;
            if (count > 0) cooldown.offer(new int[]{count, time + n});
        }
        if (!cooldown.isEmpty() && cooldown.peek()[1] == time) {
            maxHeap.offer(cooldown.poll()[0]);
        }
    }
    return time;
}
```
````
`````

**Complexity:** Time: O(total tasks × log 26) ≈ O(total) | Space: O(1) (max 26 entries)

**Edge Cases:**
- n = 0 → no idle time, answer = tasks.length
- Single task type → lots of idle slots
- All unique tasks → no idle needed if count ≤ n+1

### 133. Reorganize String — #767
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Greedy + max-heap, place most frequent alternately** — if most frequent char count > `(n+1)/2`, impossible. Otherwise, greedily alternate using heap.

`````col
````col-md
**Explanation:**
1. Count frequencies; if any > (n+1)/2 → return ""
2. Max-heap by frequency
3. Each step: poll top two chars, append both to result, re-add if count > 0
4. Guarantees no adjacent same chars
````

````col-md
**Code:**
```java
public String reorganizeString(String s) {
    int[] freq = new int[26];
    for (char c : s.toCharArray()) freq[c - 'a']++;

    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[1] - a[1]);
    for (int i = 0; i < 26; i++) {
        if (freq[i] > (s.length() + 1) / 2) return "";
        if (freq[i] > 0) pq.offer(new int[]{i, freq[i]});
    }

    StringBuilder sb = new StringBuilder();
    while (pq.size() >= 2) {
        int[] first = pq.poll(), second = pq.poll();
        sb.append((char)(first[0] + 'a'));
        sb.append((char)(second[0] + 'a'));
        if (--first[1] > 0) pq.offer(first);
        if (--second[1] > 0) pq.offer(second);
    }
    if (!pq.isEmpty()) sb.append((char)(pq.poll()[0] + 'a'));
    return sb.toString();
}
```
````
`````

**Complexity:** Time: O(n log 26) ≈ O(n) | Space: O(1)

**Edge Cases:**
- "aab" → "aba" (valid)
- "aaab" → "" (impossible)
- All same char → only valid if length 1

### 134. Merge K Sorted Lists — #23 (Heap perspective)
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Min-heap + dummy head (K-way merge)** — (Same as #81.) PQ keeps smallest head across K lists. Extract-min, link, push next node from that list.

`````col
````col-md
**Explanation:**
1. Add all non-null list heads to min-heap
2. Extract min → link to result tail
3. If extracted node has .next → push to heap
4. Repeat until heap empty
````

````col-md
**Code:**
```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode l : lists) if (l != null) pq.offer(l);
    ListNode dummy = new ListNode(0), tail = dummy;
    while (!pq.isEmpty()) {
        ListNode node = pq.poll();
        tail.next = node;
        tail = node;
        if (node.next != null) pq.offer(node.next);
    }
    return dummy.next;
}
```
````
`````

**Complexity:** Time: O(N log K) | Space: O(K)

**Edge Cases:**
- See Problem #81

### 135. Ugly Number II — #264
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Min-heap or 3-pointer DP for ordered generation** — generate ugly numbers in sorted order using three pointers (×2, ×3, ×5), each advancing independently.

`````col
````col-md
**Explanation:**
1. `dp[0] = 1`, three pointers `i2 = i3 = i5 = 0`
2. Next ugly = `min(dp[i2]*2, dp[i3]*3, dp[i5]*5)`
3. Advance pointer(s) that produced the min (handle duplicates)
4. Repeat n times
````

````col-md
**Code:**
```java
public int nthUglyNumber(int n) {
    int[] dp = new int[n];
    dp[0] = 1;
    int i2 = 0, i3 = 0, i5 = 0;
    for (int i = 1; i < n; i++) {
        int next2 = dp[i2] * 2, next3 = dp[i3] * 3, next5 = dp[i5] * 5;
        dp[i] = Math.min(next2, Math.min(next3, next5));
        if (dp[i] == next2) i2++;
        if (dp[i] == next3) i3++;
        if (dp[i] == next5) i5++;
    }
    return dp[n - 1];
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- n = 1 → return 1
- Duplicates (e.g., 6 = 2×3 = 3×2) → handled by advancing multiple pointers

### 136. Smallest Range Covering Elements from K Lists — #632
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Min-heap + track current max across K lists** — maintain one element from each list in a min-heap, track the current max. Range = [heap.min, currentMax]. Advance the min pointer to shrink range.

`````col
````col-md
**Explanation:**
1. Add first element of each list to min-heap; track global max
2. Current range = `[heap.min, currentMax]`
3. If this range is smaller → update best
4. Poll min, add next from that list, update max
5. Stop when any list is exhausted
````

````col-md
**Code:**
```java
public int[] smallestRange(List<List<Integer>> nums) {
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    int max = Integer.MIN_VALUE;
    for (int i = 0; i < nums.size(); i++) {
        int val = nums.get(i).get(0);
        pq.offer(new int[]{val, i, 0});
        max = Math.max(max, val);
    }
    int[] best = {pq.peek()[0], max};
    while (true) {
        int[] min = pq.poll();
        if (max - min[0] < best[1] - best[0]) {
            best = new int[]{min[0], max};
        }
        if (min[2] + 1 == nums.get(min[1]).size()) break;
        int next = nums.get(min[1]).get(min[2] + 1);
        max = Math.max(max, next);
        pq.offer(new int[]{next, min[1], min[2] + 1});
    }
    return best;
}
```
````
`````

**Complexity:** Time: O(N log K) where N = total elements | Space: O(K)

**Edge Cases:**
- K = 1 → range = [min, min] (single list, pick any element)
- All lists have one element → range spans all those elements
- Lists of vastly different lengths
