### 45. Two Sum — #1
**Difficulty:** Easy

**Pattern & Key Insight:**
- **HashMap (value → index), complement lookup** — for each element, check if `target - nums[i]` already exists in the map. One-pass solution.

`````col
````col-md
**Explanation:**
1. Create HashMap<Integer, Integer> (value → index)
2. For each element, compute complement = `target - nums[i]`
3. If complement in map → return both indices
4. Else put current value and index in map
````

````col-md
**Code:**
```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{};
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Same element used twice → map stores index before checking
- Negative numbers → complement can be larger than target

### 46. Valid Anagram — #242
**Difficulty:** Easy

**Pattern & Key Insight:**
- **int[26] character frequency comparison** — count chars in first string (+1), decrement with second (-1). All zeros = anagram.

`````col
````col-md
**Explanation:**
1. If lengths differ → false
2. Use `int[26]` frequency array
3. Increment for `s`, decrement for `t`
4. If all entries are 0 → true
````

````col-md
**Code:**
```java
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] freq = new int[26];
    for (int i = 0; i < s.length(); i++) {
        freq[s.charAt(i) - 'a']++;
        freq[t.charAt(i) - 'a']--;
    }
    for (int f : freq) if (f != 0) return false;
    return true;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Different lengths → false immediately
- Empty strings → true (both empty)

### 47. Top K Frequent Elements — #347
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap + bucket sort** — bucket index = frequency, value = list of elements with that frequency. Scan buckets from high to low for top K.

`````col
````col-md
**Explanation:**
1. Count frequencies with HashMap
2. Create bucket array of size `n+1`
3. Place elements into bucket at their frequency index
4. Scan from highest bucket, collect K elements
````

````col-md
**Code:**
```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);

    List<Integer>[] buckets = new List[nums.length + 1];
    for (var entry : freq.entrySet()) {
        int f = entry.getValue();
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(entry.getKey());
    }

    int[] result = new int[k];
    int idx = 0;
    for (int i = buckets.length - 1; i >= 0 && idx < k; i--) {
        if (buckets[i] != null) {
            for (int val : buckets[i]) {
                result[idx++] = val;
                if (idx == k) break;
            }
        }
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- k == number of unique elements → return all
- All elements same → single element with frequency n

### 48. Longest Consecutive Sequence — #128
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashSet + sequence-start detection** — only start counting from sequence starts (elements where `n-1` is NOT in the set). Avoids redundant work.

`````col
````col-md
**Explanation:**
1. Put all elements in a HashSet
2. For each element, check if `num - 1` is NOT in set (= start of sequence)
3. If start: count consecutive elements (`num+1, num+2, ...`)
4. Track max length
````

````col-md
**Code:**
```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);
    int maxLen = 0;
    for (int num : set) {
        if (!set.contains(num - 1)) {
            int len = 1;
            while (set.contains(num + len)) len++;
            maxLen = Math.max(maxLen, len);
        }
    }
    return maxLen;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Empty array → 0
- All same elements → length 1
- Already sorted → works without sorting

### 49. Valid Sudoku — #36
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Multi-dimensional HashSet constraint validation** — three sets: rows[9], cols[9], boxes[9]. Box index = `(r/3)*3 + c/3`.

`````col
````col-md
**Explanation:**
1. For each cell with a digit:
   - Check if digit already in `rows[r]`, `cols[c]`, or `boxes[boxIdx]`
   - If yes → invalid
   - Else add digit to all three sets
2. Box index formula: `(r/3)*3 + c/3`
````

````col-md
**Code:**
```java
public boolean isValidSudoku(char[][] board) {
    Set<Character>[] rows = new HashSet[9];
    Set<Character>[] cols = new HashSet[9];
    Set<Character>[] boxes = new HashSet[9];
    for (int i = 0; i < 9; i++) {
        rows[i] = new HashSet<>();
        cols[i] = new HashSet<>();
        boxes[i] = new HashSet<>();
    }
    for (int r = 0; r < 9; r++) {
        for (int c = 0; c < 9; c++) {
            char ch = board[r][c];
            if (ch == '.') continue;
            int box = (r / 3) * 3 + c / 3;
            if (!rows[r].add(ch) || !cols[c].add(ch) || !boxes[box].add(ch))
                return false;
        }
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(81) = O(1) | Space: O(81) = O(1)

**Edge Cases:**
- Empty cells ('.') → skip
- Partially filled → validate only filled cells

### 50. LRU Cache — #146
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap + Doubly Linked List, O(1) get & put** — HashMap gives O(1) lookup; DLL gives O(1) move-to-front and evict-last.

`````col
````col-md
**Explanation:**
1. HashMap<key, DLL_Node> for O(1) lookup
2. DLL with dummy head/tail for O(1) insert/remove
3. `get`: if exists, move node to head, return value
4. `put`: if exists, update + move to head. If new: add to head, evict tail if over capacity
````

````col-md
**Code:**
```java
class LRUCache {
    class Node { int key, val; Node prev, next; }
    Map<Integer, Node> map = new HashMap<>();
    Node head = new Node(), tail = new Node();
    int cap;

    public LRUCache(int capacity) {
        cap = capacity;
        head.next = tail; tail.prev = head;
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        Node node = map.get(key);
        remove(node); addToHead(node);
        return node.val;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;
            remove(node); addToHead(node);
        } else {
            Node node = new Node();
            node.key = key; node.val = value;
            map.put(key, node); addToHead(node);
            if (map.size() > cap) {
                Node lru = tail.prev;
                remove(lru); map.remove(lru.key);
            }
        }
    }

    private void remove(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void addToHead(Node n) { n.next = head.next; n.prev = head; head.next.prev = n; head.next = n; }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(capacity)

**Edge Cases:**
- Get non-existent key → -1
- Put existing key → update value and move to front
- Capacity 1 → every new put evicts

### 51. Insert Delete GetRandom O(1) — #380
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap + ArrayList for O(1) random access** — HashMap tracks value→index. Delete in O(1) by swapping with last element before removing.

`````col
````col-md
**Explanation:**
1. ArrayList stores values, HashMap maps value→index
2. Insert: add to end of list, record index in map
3. Delete: swap target with last element, remove last, update map
4. GetRandom: `list.get(random.nextInt(list.size()))`
````

````col-md
**Code:**
```java
class RandomizedSet {
    List<Integer> list = new ArrayList<>();
    Map<Integer, Integer> map = new HashMap<>();
    Random rand = new Random();

    public boolean insert(int val) {
        if (map.containsKey(val)) return false;
        map.put(val, list.size());
        list.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!map.containsKey(val)) return false;
        int idx = map.get(val);
        int last = list.getLast();
        list.set(idx, last);
        map.put(last, idx);
        list.removeLast();
        map.remove(val);
        return true;
    }

    public int getRandom() {
        return list.get(rand.nextInt(list.size()));
    }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(n)

**Edge Cases:**
- Remove element that's already the last → swap with itself (still works)
- Insert duplicate → return false

### 52. First Unique Character in a String — #387
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Frequency array + second pass** — count frequencies first, then find first char with count == 1. Two O(n) passes = still O(n).

`````col
````col-md
**Explanation:**
1. First pass: count frequency of each char
2. Second pass: find first char with `freq == 1`
3. Return its index (or -1 if none)
````

````col-md
**Code:**
```java
public int firstUniqChar(String s) {
    int[] freq = new int[26];
    for (char c : s.toCharArray()) freq[c - 'a']++;
    for (int i = 0; i < s.length(); i++) {
        if (freq[s.charAt(i) - 'a'] == 1) return i;
    }
    return -1;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- All chars repeated → return -1
- Single char → return 0

### 53. Ransom Note — #383
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Character frequency difference check** — check if magazine's char counts are ≥ ransomNote's char counts for every character.

`````col
````col-md
**Explanation:**
1. Count chars in magazine
2. For each char in ransomNote, decrement count
3. If any count goes negative → false
4. Otherwise → true
````

````col-md
**Code:**
```java
public boolean canConstruct(String ransomNote, String magazine) {
    int[] freq = new int[26];
    for (char c : magazine.toCharArray()) freq[c - 'a']++;
    for (char c : ransomNote.toCharArray()) {
        if (--freq[c - 'a'] < 0) return false;
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n + m) | Space: O(1)

**Edge Cases:**
- Ransom note longer than magazine → likely false
- Empty ransom note → always true

### 54. Word Pattern — #290
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Bijection mapping (two-way HashMap)** — pattern→word AND word→pattern must both be consistent. Use two maps to enforce one-to-one.

`````col
````col-md
**Explanation:**
1. Split string into words
2. If `words.length != pattern.length` → false
3. Map char→word and word→char
4. If any mapping conflicts → false
````

````col-md
**Code:**
```java
public boolean wordPattern(String pattern, String s) {
    String[] words = s.split(" ");
    if (words.length != pattern.length()) return false;
    Map<Character, String> charToWord = new HashMap<>();
    Map<String, Character> wordToChar = new HashMap<>();
    for (int i = 0; i < words.length; i++) {
        char c = pattern.charAt(i);
        String w = words[i];
        if (charToWord.containsKey(c) && !charToWord.get(c).equals(w)) return false;
        if (wordToChar.containsKey(w) && wordToChar.get(w) != c) return false;
        charToWord.put(c, w);
        wordToChar.put(w, c);
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- "abba" + "dog cat cat dog" → true
- "abba" + "dog cat cat fish" → false (a maps to both dog and fish)
- "abba" + "dog dog dog dog" → false (a and b both map to dog)

### 55. LFU Cache — #460
**Difficulty:** Hard

**Pattern & Key Insight:**
- **HashMap + frequency map + doubly linked list per frequency** — track access frequency; on eviction, remove least frequent (tie = least recently used among least frequent).

`````col
````col-md
**Explanation:**
1. `keyToVal` map, `keyToFreq` map, `freqToKeys` (LinkedHashSet per freq)
2. `get`: increment freq, move key to new freq bucket
3. `put`: if full, evict first element from lowest freq bucket
4. Track `minFreq` to find eviction target in O(1)
````

````col-md
**Code:**
```java
class LFUCache {
    Map<Integer, Integer> vals = new HashMap<>();
    Map<Integer, Integer> freqs = new HashMap<>();
    Map<Integer, LinkedHashSet<Integer>> freqToKeys = new HashMap<>();
    int cap, minFreq;

    public LFUCache(int capacity) { cap = capacity; }

    public int get(int key) {
        if (!vals.containsKey(key)) return -1;
        incrementFreq(key);
        return vals.get(key);
    }

    public void put(int key, int value) {
        if (cap <= 0) return;
        if (vals.containsKey(key)) {
            vals.put(key, value);
            incrementFreq(key);
            return;
        }
        if (vals.size() >= cap) {
            int evict = freqToKeys.get(minFreq).iterator().next();
            freqToKeys.get(minFreq).remove(evict);
            vals.remove(evict); freqs.remove(evict);
        }
        vals.put(key, value); freqs.put(key, 1); minFreq = 1;
        freqToKeys.computeIfAbsent(1, k -> new LinkedHashSet<>()).add(key);
    }

    private void incrementFreq(int key) {
        int f = freqs.get(key);
        freqs.put(key, f + 1);
        freqToKeys.get(f).remove(key);
        if (freqToKeys.get(f).isEmpty()) {
            freqToKeys.remove(f);
            if (minFreq == f) minFreq++;
        }
        freqToKeys.computeIfAbsent(f + 1, k -> new LinkedHashSet<>()).add(key);
    }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(capacity)

**Edge Cases:**
- Capacity 0 → all puts are no-ops
- Tie in frequency → evict least recently used (LinkedHashSet maintains insertion order)
