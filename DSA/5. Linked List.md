### 70. Reverse Linked List — #206
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Iterative pointer reversal (prev/curr/next)** — save next, reverse pointer, advance prev and curr. The most reused linked list snippet.

`````col
````col-md
**Explanation:**
1. `prev = null`, `curr = head`
2. While `curr != null`:
   - Save `next = curr.next`
   - Reverse: `curr.next = prev`
   - Advance: `prev = curr`, `curr = next`
3. Return `prev` (new head)
````

````col-md
**Code:**
```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Empty list → null
- Single node → returns itself
- Already reversed → re-reverses

### 71. Merge Two Sorted Lists — #21
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Dummy head + two-pointer merge** — dummy node eliminates head edge cases. Compare and link smaller node each step.

`````col
````col-md
**Explanation:**
1. Create dummy node, `tail = dummy`
2. While both lists non-null:
   - Link smaller node to tail
   - Advance that list's pointer
3. Attach remaining non-null list
4. Return `dummy.next`
````

````col-md
**Code:**
```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
        else { tail.next = l2; l2 = l2.next; }
        tail = tail.next;
    }
    tail.next = l1 != null ? l1 : l2;
    return dummy.next;
}
```
````
`````

**Complexity:** Time: O(n + m) | Space: O(1)

**Edge Cases:**
- One list empty → return the other
- Both empty → null
- One element each → linked in order

### 72. Remove Nth Node From End — #19
**Difficulty:** Medium

**Pattern & Key Insight:**
- **N-gap two pointers + dummy head** — advance fast pointer N steps ahead. Then move both until fast reaches end. Slow is just before the target.

`````col
````col-md
**Explanation:**
1. Dummy node before head (handles removing head)
2. `fast` advances `n+1` steps from dummy
3. Move `slow` and `fast` together until `fast == null`
4. `slow.next = slow.next.next` (skip target)
5. Return `dummy.next`
````

````col-md
**Code:**
```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next;
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Remove head (n == list length) → dummy handles it
- Single node, n=1 → returns null

### 73. Swap Nodes in Pairs — #24
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Iterative pointer re-wiring** — for each pair, re-wire: `prev → second → first → next_pair`. Careful pointer management.

`````col
````col-md
**Explanation:**
1. Dummy node, `prev = dummy`
2. While two nodes ahead exist:
   - `first = prev.next`, `second = first.next`
   - Re-wire: `prev.next = second`, `first.next = second.next`, `second.next = first`
   - Advance: `prev = first`
3. Return `dummy.next`
````

````col-md
**Code:**
```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0, head), prev = dummy;
    while (prev.next != null && prev.next.next != null) {
        ListNode first = prev.next, second = first.next;
        prev.next = second;
        first.next = second.next;
        second.next = first;
        prev = first;
    }
    return dummy.next;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Odd number of nodes → last node stays in place
- Single node → unchanged
- Empty list → null

### 74. Reverse Nodes in k-Group — #25
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Reversal in segments + connection** — count k nodes ahead, reverse that segment, connect segments. Combines #206 with boundary tracking.

`````col
````col-md
**Explanation:**
1. Count if k nodes exist; if not, leave as-is
2. Reverse k nodes (same as #206)
3. Connect: previous group's tail → new head of reversed segment
4. The old head of segment is now the tail → connects to next segment
5. Recurse or iterate for next group
````

````col-md
**Code:**
```java
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0, head), prevGroup = dummy;
    while (true) {
        ListNode kth = prevGroup;
        for (int i = 0; i < k; i++) {
            kth = kth.next;
            if (kth == null) return dummy.next;
        }
        ListNode nextGroup = kth.next;
        ListNode prev = nextGroup, curr = prevGroup.next;
        for (int i = 0; i < k; i++) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        ListNode tmp = prevGroup.next;
        prevGroup.next = prev;
        prevGroup = tmp;
    }
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- k = 1 → no change
- k > list length → no reversal
- Exact multiple of k → all groups reversed

### 75. Linked List Cycle — #141
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Floyd's fast/slow pointer (cycle detection)** — slow moves 1, fast moves 2. If they meet → cycle exists. If fast hits null → no cycle.

`````col
````col-md
**Explanation:**
1. `slow = head`, `fast = head`
2. While `fast != null && fast.next != null`:
   - `slow = slow.next`
   - `fast = fast.next.next`
   - If `slow == fast` → cycle exists
3. Return false (no cycle)
````

````col-md
**Code:**
```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Empty list / single node without cycle → false
- Cycle of length 1 (self-loop)

### 76. Linked List Cycle II — #142
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Floyd's — find cycle entry point** — after meeting, reset one pointer to head. Both advance at speed 1 — they meet at the cycle entry. Mathematical proof: distance from head to entry = distance from meeting point to entry.

`````col
````col-md
**Explanation:**
1. Detect cycle (fast/slow meet)
2. Reset `slow` to head
3. Both move 1 step at a time
4. They meet at the cycle entry node
5. Return that node (or null if no cycle)
````

````col-md
**Code:**
```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            slow = head;
            while (slow != fast) {
                slow = slow.next;
                fast = fast.next;
            }
            return slow;
        }
    }
    return null;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- No cycle → null
- Cycle starts at head → they meet at head
- Long tail before cycle

### 78. Palindrome Linked List — #234
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Find middle + reverse second half + compare** — compose three patterns: #876 (mid) + #206 (reverse) + two-pointer compare.

`````col
````col-md
**Explanation:**
1. Find middle using fast/slow
2. Reverse second half starting from `slow`
3. Compare first half with reversed second half
4. If all match → palindrome
````

````col-md
**Code:**
```java
public boolean isPalindrome(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode rev = reverse(slow);
    while (rev != null) {
        if (head.val != rev.val) return false;
        head = head.next;
        rev = rev.next;
    }
    return true;
}

private ListNode reverse(ListNode head) {
    ListNode prev = null;
    while (head != null) {
        ListNode next = head.next;
        head.next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Single node → true
- Two nodes same value → true
- Odd length → middle element doesn't affect result

### 79. Intersection of Two Linked Lists — #160
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Two pointers with path-length equalization** — pointer A traverses listA then listB; pointer B traverses listB then listA. They meet at intersection (or both reach null).

`````col
````col-md
**Explanation:**
1. `a = headA`, `b = headB`
2. When `a` reaches end → switch to `headB`
3. When `b` reaches end → switch to `headA`
4. They meet at intersection or both become null
5. Total traversal equalizes path lengths
````

````col-md
**Code:**
```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode a = headA, b = headB;
    while (a != b) {
        a = a == null ? headB : a.next;
        b = b == null ? headA : b.next;
    }
    return a;
}
```
````
`````

**Complexity:** Time: O(n + m) | Space: O(1)

**Edge Cases:**
- No intersection → both reach null simultaneously
- Same starting node → returns head immediately
- Different lengths → pointer switching equalizes

### 80. Reorder List — #143
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Find mid + reverse second half + merge alternating** — three algorithms in sequence: split at mid, reverse back half, interleave merge.

`````col
````col-md
**Explanation:**
1. Find middle (fast/slow)
2. Reverse second half
3. Merge: alternate between first half and reversed second half
   - `first.next = second`, advance first
   - `second.next = first`, advance second
````

````col-md
**Code:**
```java
public void reorderList(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode second = reverse(slow.next);
    slow.next = null;
    ListNode first = head;
    while (second != null) {
        ListNode tmp1 = first.next, tmp2 = second.next;
        first.next = second;
        second.next = tmp1;
        first = tmp1;
        second = tmp2;
    }
}

private ListNode reverse(ListNode head) {
    ListNode prev = null;
    while (head != null) {
        ListNode next = head.next;
        head.next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- 1 or 2 nodes → no reordering needed
- Odd length → middle node stays in place

### 81. Merge K Sorted Lists — #23
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Min-heap (PriorityQueue) + dummy head** — PQ keeps track of the smallest current node across all K lists. Extract min, link, add next from that list.

`````col
````col-md
**Explanation:**
1. Add all list heads to a min-heap (compare by val)
2. Extract min node, link to result
3. If extracted node has next → add next to heap
4. Repeat until heap empty
````

````col-md
**Code:**
```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>(
        (a, b) -> a.val - b.val);
    for (ListNode l : lists) if (l != null) pq.offer(l);
    ListNode dummy = new ListNode(0), tail = dummy;
    while (!pq.isEmpty()) {
        ListNode node = pq.poll();
        tail.next = node;
        tail = tail.next;
        if (node.next != null) pq.offer(node.next);
    }
    return dummy.next;
}
```
````
`````

**Complexity:** Time: O(N log K) where N = total nodes | Space: O(K)

**Edge Cases:**
- Empty lists array → null
- Some lists are null → skip in initialization
- K = 1 → return that list directly

### 83. Copy List with Random Pointer — #138
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap (original → clone) or interleaving trick** — HashMap maps each original node to its clone, allowing random pointer reconstruction. O(1) space alternative: interleave clones between originals.

`````col
````col-md
**Explanation:**
HashMap approach:
1. First pass: clone all nodes, store in map (original → clone)
2. Second pass: set next and random pointers using map lookups
3. Return map.get(head)
````

````col-md
**Code:**
```java
public Node copyRandomList(Node head) {
    if (head == null) return null;
    Map<Node, Node> map = new HashMap<>();
    Node curr = head;
    while (curr != null) {
        map.put(curr, new Node(curr.val));
        curr = curr.next;
    }
    curr = head;
    while (curr != null) {
        map.get(curr).next = map.get(curr.next);
        map.get(curr).random = map.get(curr.random);
        curr = curr.next;
    }
    return map.get(head);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Random pointer is null → clone's random is null
- Random points to self → clone points to clone-self
- Empty list → null
