### 243. Longest Substring with At Most K Distinct Characters — #340
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Variable sliding window + HashMap (char → count)** — expand right always; shrink left when distinct count > k. Classic "at most K distinct" template.

`````col
````col-md
**Explanation:**
1. HashMap tracks char → frequency in window
2. Expand right: add char, increment count
3. While map.size() > k: shrink left, decrement, remove if 0
4. Update max length
````

````col-md
**Code:**
```java
public int lengthOfLongestSubstringKDistinct(String s, int k) {
    Map<Character, Integer> map = new HashMap<>();
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        map.merge(s.charAt(right), 1, Integer::sum);
        while (map.size() > k) {
            char lc = s.charAt(left++);
            if (map.merge(lc, -1, Integer::sum) == 0) map.remove(lc);
        }
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(k)

**Edge Cases:**
- k = 0 → 0
- k >= unique chars → entire string
- All same chars → entire string

### 244. Minimum Remove to Make Valid Parentheses — #1249
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Stack for index tracking + string rebuild** — stack stores indices of unmatched '('. On ')', if stack has unmatched '(' → pop (matched). Else mark ')' for removal.

`````col
````col-md
**Explanation:**
1. First pass: stack tracks unmatched '(' indices; mark unmatched ')' positions
2. After scan: remaining stack entries = unmatched '(' → mark those too
3. Rebuild string skipping all marked positions
````

````col-md
**Code:**
```java
public String minRemoveToMakeValid(String s) {
    Set<Integer> remove = new HashSet<>();
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == '(') stack.push(i);
        else if (s.charAt(i) == ')') {
            if (stack.isEmpty()) remove.add(i);
            else stack.pop();
        }
    }
    while (!stack.isEmpty()) remove.add(stack.pop());
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++)
        if (!remove.contains(i)) sb.append(s.charAt(i));
    return sb.toString();
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Already valid → unchanged
- All '(' or all ')' → all removed
- No parentheses → unchanged

### 245. Subarray Product Less Than K — #713
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Sliding window with product tracking** — maintain running product; shrink when product ≥ k. Count subarrays ending at each right = `right - left + 1`.

`````col
````col-md
**Explanation:**
1. `left = 0`, `product = 1`
2. Expand right: `product *= nums[right]`
3. While `product >= k`: `product /= nums[left++]`
4. Count += `right - left + 1` (all subarrays ending at right)
````

````col-md
**Code:**
```java
public int numSubarrayProductLessThanK(int[] nums, int k) {
    if (k <= 1) return 0;
    int left = 0, count = 0, product = 1;
    for (int right = 0; right < nums.length; right++) {
        product *= nums[right];
        while (product >= k) product /= nums[left++];
        count += right - left + 1;
    }
    return count;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- k <= 1 → 0 (all products ≥ 1 since nums[i] ≥ 1)
- All elements = 1 → every subarray valid if k > 1
- Single element >= k → that subarray not counted

### 246. Maximum XOR of Two Numbers in Array — #421
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Trie on binary representation (bit-by-bit greedy)** — build a bitwise trie of all numbers. For each number, greedily choose the opposite bit at each level to maximize XOR.

`````col
````col-md
**Explanation:**
1. Build trie from MSB to LSB (31 bits) for each number
2. For each number: traverse trie, at each bit try the opposite bit
   - If opposite exists → take it (that bit contributes to XOR)
   - Else → take same bit
3. Track max XOR across all numbers
````

````col-md
**Code:**
```java
public int findMaximumXOR(int[] nums) {
    int[][] trie = new int[nums.length * 32][2];
    int idx = 1;
    for (int num : nums) {
        int node = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (trie[node][bit] == 0) trie[node][bit] = idx++;
            node = trie[node][bit];
        }
    }
    int max = 0;
    for (int num : nums) {
        int node = 0, xor = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit;
            if (trie[node][want] != 0) { xor |= (1 << i); node = trie[node][want]; }
            else node = trie[node][bit];
        }
        max = Math.max(max, xor);
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(32n) = O(n) | Space: O(32n)

**Edge Cases:**
- Two elements → just XOR them
- All same → XOR = 0
- Power of 2 values → bit patterns simplify

### 247. Critical Connections in a Network — #1192
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Tarjan's bridge-finding algorithm (DFS + low-link values)** — track discovery time and lowest reachable ancestor. An edge (u,v) is a bridge if `low[v] > disc[u]`.

`````col
````col-md
**Explanation:**
1. DFS assigning discovery time `disc[u]` and `low[u]`
2. `low[u]` = min(disc[u], low of all non-parent DFS neighbors)
3. After visiting child v: if `low[v] > disc[u]` → edge (u,v) is a bridge
4. Bridges = critical connections
````

````col-md
**Code:**
```java
int time = 0;

public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
    List<List<Integer>> graph = new ArrayList<>(), result = new ArrayList<>();
    for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
    for (var e : connections) { graph.get(e.get(0)).add(e.get(1)); graph.get(e.get(1)).add(e.get(0)); }
    int[] disc = new int[n], low = new int[n];
    Arrays.fill(disc, -1);
    dfs(graph, 0, -1, disc, low, result);
    return result;
}

private void dfs(List<List<Integer>> graph, int u, int parent, int[] disc, int[] low, List<List<Integer>> result) {
    disc[u] = low[u] = time++;
    for (int v : graph.get(u)) {
        if (v == parent) continue;
        if (disc[v] == -1) {
            dfs(graph, v, u, disc, low, result);
            low[u] = Math.min(low[u], low[v]);
            if (low[v] > disc[u]) result.add(List.of(u, v));
        } else {
            low[u] = Math.min(low[u], disc[v]);
        }
    }
}
```
````
`````

**Complexity:** Time: O(V + E) | Space: O(V + E)

**Edge Cases:**
- Tree (all edges are bridges) → return all edges
- Complete graph → no bridges
- Single bridge connecting two components

### 248. Longest Valid Parentheses — #32
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Stack-based — index tracking for longest valid bracket substring** — stack stores indices of unmatched brackets. Length = `current index - stack.peek()`.

`````col
````col-md
**Explanation:**
1. Push -1 as base (boundary before first valid sequence)
2. For each char:
   - '(' → push index
   - ')' → pop; if stack empty → push current index as new base
   - Else → length = `i - stack.peek()`; update max
````

````col-md
**Code:**
```java
public int longestValidParentheses(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(-1);
    int max = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == '(') {
            stack.push(i);
        } else {
            stack.pop();
            if (stack.isEmpty()) stack.push(i);
            else max = Math.max(max, i - stack.peek());
        }
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- All open "(((" → 0
- All close ")))" → 0
- Entire string valid → length = n

### 249. Number of Longest Increasing Subsequence — #673
**Difficulty:** Medium

**Pattern & Key Insight:**
- **DP tracking both LIS length AND count at each index** — `dp[i]` = length of LIS ending at i. `count[i]` = number of LIS of that length ending at i.

`````col
````col-md
**Explanation:**
1. For each i, for each j < i where nums[j] < nums[i]:
   - If `dp[j] + 1 > dp[i]` → new longer: dp[i] = dp[j]+1, count[i] = count[j]
   - If `dp[j] + 1 == dp[i]` → same length: count[i] += count[j]
2. Find max length, sum all count[i] where dp[i] == maxLen
````

````col-md
**Code:**
```java
public int findNumberOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n], count = new int[n];
    Arrays.fill(dp, 1);
    Arrays.fill(count, 1);
    int maxLen = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                if (dp[j] + 1 > dp[i]) { dp[i] = dp[j] + 1; count[i] = count[j]; }
                else if (dp[j] + 1 == dp[i]) count[i] += count[j];
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    int total = 0;
    for (int i = 0; i < n; i++) if (dp[i] == maxLen) total += count[i];
    return total;
}
```
````
`````

**Complexity:** Time: O(n²) | Space: O(n)

**Edge Cases:**
- All same → every single element is LIS of length 1 → count = n
- Strictly increasing → 1 LIS of length n
- Multiple LIS paths

### 250. Design Circular Deque — #641
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Circular buffer with front/rear pointers** — extends circular queue with both-end operations. `front` moves backward on insertFront, `rear` moves forward on insertLast.

`````col
````col-md
**Explanation:**
1. Array of size k, `front = 0`, `rear = 0`, `size = 0`
2. insertFront: `front = (front - 1 + k) % k`, place element
3. insertLast: place at rear, `rear = (rear + 1) % k`
4. deleteFront: `front = (front + 1) % k`
5. deleteLast: `rear = (rear - 1 + k) % k`
````

````col-md
**Code:**
```java
class MyCircularDeque {
    int[] data;
    int front, rear, size, cap;

    public MyCircularDeque(int k) { data = new int[k]; cap = k; front = 0; rear = 0; }

    public boolean insertFront(int value) {
        if (isFull()) return false;
        front = (front - 1 + cap) % cap;
        data[front] = value;
        size++;
        return true;
    }

    public boolean insertLast(int value) {
        if (isFull()) return false;
        data[rear] = value;
        rear = (rear + 1) % cap;
        size++;
        return true;
    }

    public boolean deleteFront() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        size--;
        return true;
    }

    public boolean deleteLast() {
        if (isEmpty()) return false;
        rear = (rear - 1 + cap) % cap;
        size--;
        return true;
    }

    public int getFront() { return isEmpty() ? -1 : data[front]; }
    public int getRear() { return isEmpty() ? -1 : data[(rear - 1 + cap) % cap]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == cap; }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(k)

**Edge Cases:**
- Insert when full → false
- Delete when empty → false
- Wrap-around on both ends simultaneously
