### 101. Invert Binary Tree — #226
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Pre-order DFS — swap children, then recurse** — at each node, swap left and right, then recurse into both. Simplest recursive tree problem.

`````col
````col-md
**Explanation:**
1. If node is null → return null
2. Swap `node.left` and `node.right`
3. Recurse on both children
4. Return node
````

````col-md
**Code:**
```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode tmp = root.left;
    root.left = root.right;
    root.right = tmp;
    invertTree(root.left);
    invertTree(root.right);
    return root;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h) recursion stack

**Edge Cases:**
- Empty tree → null
- Single node → unchanged
- Already symmetric → inverting changes it

### 102. Path Sum — #112
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Top-down DFS with running sum (subtract as you go)** — subtract node value from target while descending. At a leaf, check if remaining == 0.

`````col
````col-md
**Explanation:**
1. If null → false
2. Subtract `node.val` from `targetSum`
3. If leaf AND `targetSum == 0` → true
4. Recurse left OR right
````

````col-md
**Code:**
```java
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    targetSum -= root.val;
    if (root.left == null && root.right == null) return targetSum == 0;
    return hasPathSum(root.left, targetSum) || hasPathSum(root.right, targetSum);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- Empty tree → false
- Root is leaf → check root.val == targetSum
- Negative values in tree

### 103. Path Sum II — #113
**Difficulty:** Medium

**Pattern & Key Insight:**
- **DFS with path list + backtracking** — add node to path, recurse, remove last (backtrack). Collect valid paths at leaves.

`````col
````col-md
**Explanation:**
1. Maintain current path list
2. Add node value, subtract from target
3. If leaf and target == 0 → add copy of path to results
4. Recurse left and right
5. Backtrack: remove last element
````

````col-md
**Code:**
```java
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> result = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), result);
    return result;
}

private void dfs(TreeNode node, int target, List<Integer> path, List<List<Integer>> result) {
    if (node == null) return;
    path.add(node.val);
    if (node.left == null && node.right == null && target == node.val) {
        result.add(new ArrayList<>(path));
    }
    dfs(node.left, target - node.val, path, result);
    dfs(node.right, target - node.val, path, result);
    path.removeLast();
}
```
````
`````

**Complexity:** Time: O(n²) worst case (copying paths) | Space: O(h)

**Edge Cases:**
- Multiple valid paths → all collected
- No valid path → empty result

### 106. Diameter of Binary Tree — #543
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Post-order DFS — return height, record global max** — what you return (height) differs from what you record (diameter = leftHeight + rightHeight). This "split" is key.

`````col
````col-md
**Explanation:**
1. At each node: compute left and right heights
2. Diameter through this node = `left + right`
3. Update global max diameter
4. Return `1 + max(left, right)` as height to parent
````

````col-md
**Code:**
```java
int diameter = 0;

public int diameterOfBinaryTree(TreeNode root) {
    height(root);
    return diameter;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    int right = height(node.right);
    diameter = Math.max(diameter, left + right);
    return 1 + Math.max(left, right);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- Single node → diameter = 0
- Diameter doesn't pass through root (in subtree)

### 107. Balanced Binary Tree — #110
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Post-order DFS with -1 sentinel for early termination** — return -1 to propagate "unbalanced" upward without extra boolean.

`````col
````col-md
**Explanation:**
1. If null → return 0
2. Get left and right heights
3. If either returns -1 → unbalanced → return -1
4. If `|left - right| > 1` → return -1
5. Else return `1 + max(left, right)`
````

````col-md
**Code:**
```java
public boolean isBalanced(TreeNode root) {
    return checkHeight(root) != -1;
}

private int checkHeight(TreeNode node) {
    if (node == null) return 0;
    int left = checkHeight(node.left);
    if (left == -1) return -1;
    int right = checkHeight(node.right);
    if (right == -1) return -1;
    if (Math.abs(left - right) > 1) return -1;
    return 1 + Math.max(left, right);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- Empty tree → balanced (true)
- Skewed tree → unbalanced

### 108. Binary Tree Maximum Path Sum — #124
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Post-order DFS — extend to parent OR complete path through node** — return `node.val + max(0, left, right)` to parent; record `left + node + right` as candidate. The hardest "return vs record" split.

`````col
````col-md
**Explanation:**
1. At each node: compute `leftGain = max(0, left)`, `rightGain = max(0, right)`
2. Path through node = `node.val + leftGain + rightGain` → candidate for max
3. Return to parent: `node.val + max(leftGain, rightGain)` (can only extend one side)
4. Track global max
````

````col-md
**Code:**
```java
int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    gain(root);
    return maxSum;
}

private int gain(TreeNode node) {
    if (node == null) return 0;
    int left = Math.max(0, gain(node.left));
    int right = Math.max(0, gain(node.right));
    maxSum = Math.max(maxSum, node.val + left + right);
    return node.val + Math.max(left, right);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- All negatives → max is the least negative single node
- Path is a single node → valid

### 109. Count Good Nodes in Binary Tree — #1448
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Pre-order DFS passing running maximum downward** — node is "good" if its value ≥ all ancestors. Thread max seen so far from root.

`````col
````col-md
**Explanation:**
1. DFS with `maxSoFar` parameter
2. If `node.val >= maxSoFar` → it's a good node, count it
3. Update `maxSoFar = max(maxSoFar, node.val)`
4. Recurse left and right with updated max
````

````col-md
**Code:**
```java
public int goodNodes(TreeNode root) {
    return dfs(root, Integer.MIN_VALUE);
}

private int dfs(TreeNode node, int maxSoFar) {
    if (node == null) return 0;
    int count = node.val >= maxSoFar ? 1 : 0;
    maxSoFar = Math.max(maxSoFar, node.val);
    return count + dfs(node.left, maxSoFar) + dfs(node.right, maxSoFar);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- Root is always good
- All nodes same value → all good
- Strictly decreasing path → only root is good

### 110. Binary Tree Level Order Traversal — #102
**Difficulty:** Medium

**Pattern & Key Insight:**
- **BFS with `int size = queue.size()` level snapshot** — capture level size before processing, so you know exactly which nodes belong to current level.

`````col
````col-md
**Explanation:**
1. Add root to queue
2. While queue not empty:
   - `size = queue.size()` (level boundary)
   - Process `size` nodes, add their children
   - Collect level values in a list
3. Add level list to result
````

````col-md
**Code:**
```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Empty tree → empty result
- Single node → [[val]]
- Skewed tree → each level has 1 element

### 111. Binary Tree Right Side View — #199
**Difficulty:** Medium

**Pattern & Key Insight:**

`````col
````col-md
**Explanation:**
1. BFS with level size tracking
2. For each level, the last node processed is the rightmost
3. Add only that last node's value to result
````

````col-md

```java
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> result = new ArrayList<>();
`````

### 112. Binary Tree Zigzag Level Order Traversal — #103
**Difficulty:** Medium

**Pattern & Key Insight:**
- **BFS with alternating direction flag** — same BFS template, toggle a `leftToRight` boolean each level. On reverse levels, add to front of level list.

`````col
````col-md
**Explanation:**
1. Standard BFS with level size
2. Toggle `leftToRight` flag each level
3. If left-to-right: add to end of level list
4. If right-to-left: add to front (or reverse after)
````

````col-md
**Code:**
```java
public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    boolean leftToRight = true;
    while (!queue.isEmpty()) {
        int size = queue.size();
        LinkedList<Integer> level = new LinkedList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (leftToRight) level.addLast(node.val);
            else level.addFirst(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
        leftToRight = !leftToRight;
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Single node → [[val]] (no zigzag effect)
- Two levels → first L-R, second R-L

### 113. Average of Levels in Binary Tree — #637
**Difficulty:** Easy

**Pattern & Key Insight:**
- **BFS level-order — aggregate per level** — compute sum per level, divide by level size. Reinforces the level-size BFS template.

`````col
````col-md
**Explanation:**
1. Standard BFS with level size
2. Sum all values in level
3. Divide by size → level average
4. Use double to avoid integer overflow
````

````col-md
**Code:**
```java
public List<Double> averageOfLevels(TreeNode root) {
    List<Double> result = new ArrayList<>();
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        double sum = 0;
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            sum += node.val;
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(sum / size);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Single node → [node.val]
- Large values → use double to prevent overflow

**Difficulty:** Medium

### 118. Lowest Common Ancestor of a BST — #235
**Difficulty:** Medium

**Pattern & Key Insight:**
- **BST ordering to navigate without full traversal** — both values smaller → go left; both larger → go right; split → current node is LCA.

`````col
````col-md
**Explanation:**
1. Start at root
2. If both p and q < node → LCA is in left subtree
3. If both p and q > node → LCA is in right subtree
4. Otherwise (split or match) → current node is LCA
````

````col-md
**Code:**
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    while (root != null) {
        if (p.val < root.val && q.val < root.val) root = root.left;
        else if (p.val > root.val && q.val > root.val) root = root.right;
        else return root;
    }
    return null;
}
```
````
`````

**Complexity:** Time: O(h) | Space: O(1) iterative

**Edge Cases:**
- One of p/q is the root → root is LCA
- p == q → that node is LCA

### 119. Lowest Common Ancestor of a Binary Tree — #236
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Post-order DFS — if both sides return non-null, current is LCA** — left found one, right found the other → current node is their LCA.

`````col
````col-md
**Explanation:**
1. If null or node is p or q → return node
2. Recurse left, recurse right
3. If both non-null → current is LCA
4. If one is null → return the non-null side
````

````col-md
**Code:**
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(h)

**Edge Cases:**
- p is ancestor of q → p is the LCA
- Both in left subtree → LCA is in left

### 120. Kth Smallest Element in a BST — #230
**Difficulty:** Medium

**Pattern & Key Insight:**
- **In-order traversal = sorted BST output** — in-order visits nodes in ascending order. Count to k-th visit.

`````col
````col-md
**Explanation:**
1. Iterative in-order using explicit stack
2. Go left as far as possible (push all)
3. Pop → that's next smallest; decrement k
4. If k == 0 → return that node's value
5. Move to right subtree
````

````col-md
**Code:**
```java
public int kthSmallest(TreeNode root, int k) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        if (--k == 0) return curr.val;
        curr = curr.right;
    }
    return -1;
}
```
````
`````

**Complexity:** Time: O(H + k) | Space: O(H)

**Edge Cases:**
- k = 1 → leftmost node
- k = n → rightmost node

### 121. Construct Binary Tree from Preorder and Inorder — #105
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Recursive tree construction using index splits** — preorder[0] = root. Find root in inorder → splits left/right subtrees. Use index boundaries.

`````col
````col-md
**Explanation:**
1. First element of preorder = root
2. Find root's position in inorder → left subtree = inorder[0..pos-1]
3. Left subtree size determines preorder split
4. Recurse for left and right subtrees
5. HashMap for O(1) inorder index lookup
````

````col-md
**Code:**
```java
Map<Integer, Integer> inMap = new HashMap<>();
int preIdx = 0;

public TreeNode buildTree(int[] preorder, int[] inorder) {
    for (int i = 0; i < inorder.length; i++) inMap.put(inorder[i], i);
    return build(preorder, 0, inorder.length - 1);
}

private TreeNode build(int[] preorder, int inLeft, int inRight) {
    if (inLeft > inRight) return null;
    int rootVal = preorder[preIdx++];
    TreeNode root = new TreeNode(rootVal);
    int inIdx = inMap.get(rootVal);
    root.left = build(preorder, inLeft, inIdx - 1);
    root.right = build(preorder, inIdx + 1, inRight);
    return root;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Single element → leaf node
- All left children (skewed) → preorder = reverse of inorder

### 122. Serialize and Deserialize Binary Tree — #297
**Difficulty:** Hard

**Pattern & Key Insight:**
- **BFS/DFS serialization with null markers** — use "null" markers for absent children. Preorder DFS is simplest: serialize = DFS with null markers; deserialize = consume tokens in same order.

`````col
````col-md
**Explanation:**
1. Serialize: preorder DFS, append "val," or "null,"
2. Deserialize: split by comma, consume tokens with a queue
3. If token is "null" → return null
4. Else → create node, recurse left then right
````

````col-md
**Code:**
```java
public String serialize(TreeNode root) {
    if (root == null) return "null";
    return root.val + "," + serialize(root.left) + "," + serialize(root.right);
}

public TreeNode deserialize(String data) {
    Queue<String> queue = new LinkedList<>(Arrays.asList(data.split(",")));
    return buildTree(queue);
}

private TreeNode buildTree(Queue<String> queue) {
    String val = queue.poll();
    if ("null".equals(val)) return null;
    TreeNode node = new TreeNode(Integer.parseInt(val));
    node.left = buildTree(queue);
    node.right = buildTree(queue);
    return node;
}
```
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Empty tree → "null"
- Negative values → Integer.parseInt handles them
- Very deep tree → recursion depth concern (iterative alternative exists)

### 124. Binary Tree Vertical Order Traversal — #314 / #987
**Difficulty:** Medium

**Pattern & Key Insight:**
- **BFS + column tracking with TreeMap** — assign columns (root=0, left=col-1, right=col+1). BFS ensures top-to-bottom order. TreeMap sorts columns.

`````col
````col-md
**Explanation:**
1. BFS with queue of (node, column) pairs
2. Map column → list of values (TreeMap for sorted keys)
3. Process level by level
4. Root at col 0, left child col-1, right child col+1
5. Return values grouped by column (sorted by column)
````

````col-md
**Code:**
```java
public List<List<Integer>> verticalOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    TreeMap<Integer, List<Integer>> map = new TreeMap<>();
    Queue<Object[]> queue = new LinkedList<>();
    queue.offer(new Object[]{root, 0});
    while (!queue.isEmpty()) {
        Object[] curr = queue.poll();
        TreeNode node = (TreeNode) curr[0];
        int col = (int) curr[1];
        map.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);
        if (node.left != null) queue.offer(new Object[]{node.left, col - 1});
        if (node.right != null) queue.offer(new Object[]{node.right, col + 1});
    }
    result.addAll(map.values());
    return result;
}
```
````
`````

**Complexity:** Time: O(n log n) due to TreeMap | Space: O(n)

**Edge Cases:**
- Multiple nodes in same column → BFS gives top-to-bottom order
- Symmetric tree → column 0 has multiple nodes
- Single node → [[val]]
