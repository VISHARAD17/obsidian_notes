### 84. Valid Parentheses — #20
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Stack for bracket matching** — push opens, pop on close and verify match. Stack empty at end = valid.

`````col
````col-md
**Explanation:**
1. For each char:
   - If opening bracket → push corresponding close
   - If closing bracket → pop and check match
   - If stack empty on pop or mismatch → false
2. Return `stack.isEmpty()`
````

````col-md
**Code:**
```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '{') stack.push('}');
        else if (c == '[') stack.push(']');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Odd length → always false
- Only opening brackets → stack not empty → false
- Empty string → true

### 85. Min Stack — #155
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Auxiliary stack tracking running minimum** — a parallel stack stores the minimum at each level. O(1) getMin() at all times.

`````col
````col-md
**Explanation:**
1. Main stack for values
2. Min stack: push `min(val, minStack.peek())` on every push
3. Pop both stacks together
4. `getMin()` = `minStack.peek()`
````

````col-md
**Code:**
```java
class MinStack {
    Deque<Integer> stack = new ArrayDeque<>();
    Deque<Integer> minStack = new ArrayDeque<>();

    public void push(int val) {
        stack.push(val);
        minStack.push(minStack.isEmpty() ? val : Math.min(val, minStack.peek()));
    }

    public void pop() { stack.pop(); minStack.pop(); }
    public int top() { return stack.peek(); }
    public int getMin() { return minStack.peek(); }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(n)

**Edge Cases:**
- Multiple elements with same min → min stack has duplicates
- Pop the current min → next min is revealed

### 86. Implement Stack using Queues — #225
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Simulate stack with queue rotation** — on push, add element then rotate all previous elements behind it (makes new element the front).

`````col
````col-md
**Explanation:**
1. Use single queue
2. On push: add element, then rotate `size-1` elements (poll and re-add)
3. Now front of queue = top of stack
4. Pop/top = queue.poll()/queue.peek()
````

````col-md
**Code:**
```java
class MyStack {
    Queue<Integer> queue = new LinkedList<>();

    public void push(int x) {
        queue.offer(x);
        for (int i = 0; i < queue.size() - 1; i++) {
            queue.offer(queue.poll());
        }
    }

    public int pop() { return queue.poll(); }
    public int top() { return queue.peek(); }
    public boolean empty() { return queue.isEmpty(); }
}
```
````
`````

**Complexity:** Time: O(n) push, O(1) pop/top | Space: O(n)

**Edge Cases:**
- Empty stack → empty() returns true
- Single element → push rotation does nothing

### 87. Daily Temperatures — #739
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Monotonic decreasing stack (Next Greater Element)** — stack stores indices of elements waiting for a warmer day. When a warmer day found, pop and record distance.

`````col
````col-md
**Explanation:**
1. Stack stores indices in decreasing temperature order
2. For each day `i`:
   - While stack not empty AND `temps[i] > temps[stack.peek()]`:
     - Pop index `j`, set `result[j] = i - j`
   - Push `i`
3. Remaining indices in stack → result stays 0
````

````col-md
**Code:**
```java
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] result = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
            int j = stack.pop();
            result[j] = i - j;
        }
        stack.push(i);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Strictly decreasing → all results are 0
- Strictly increasing → each waits 1 day
- All same temperature → all 0

### 88. Next Greater Element I — #496
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Monotonic stack + HashMap for cross-array lookup** — precompute NGE for nums2 into a map, then answer queries for nums1 in O(1).

`````col
````col-md
**Explanation:**
1. Process nums2 with monotonic stack → build map (element → next greater)
2. For each element in nums1, lookup in map
3. If not in map → -1
````

````col-md
**Code:**
```java
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    Map<Integer, Integer> nge = new HashMap<>();
    Deque<Integer> stack = new ArrayDeque<>();
    for (int num : nums2) {
        while (!stack.isEmpty() && stack.peek() < num) {
            nge.put(stack.pop(), num);
        }
        stack.push(num);
    }
    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nge.getOrDefault(nums1[i], -1);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n + m) | Space: O(n)

**Edge Cases:**
- No next greater exists → -1
- nums1 is subset of nums2 (guaranteed)

### 89. Next Greater Element II — #503
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Monotonic stack on circular array (modular index)** — process array twice (2n iterations) using `i % n` to simulate circularity.

`````col
````col-md
**Explanation:**
1. Initialize result with -1
2. Iterate `i` from 0 to `2n - 1`
3. Use `i % n` as actual index
4. Standard monotonic stack logic
5. Second pass wraps around to find circular NGE
````

````col-md
**Code:**
```java
public int[] nextGreaterElements(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < 2 * n; i++) {
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i % n]) {
            result[stack.pop()] = nums[i % n];
        }
        if (i < n) stack.push(i);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- All same elements → all -1
- Strictly increasing then one small → wraps around

### 90. Car Fleet — #853
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Sort + stack to simulate merging events** — sort by position descending, compute arrival time. If a car arrives ≤ the car ahead, it merges (doesn't form new fleet).

`````col
````col-md
**Explanation:**
1. Pair positions with speeds, sort by position descending
2. Compute arrival time for each: `(target - pos) / speed`
3. Use stack: if current arrival time > stack top → new fleet (push)
4. Else → merges with fleet ahead (skip)
5. Stack size = number of fleets
````

````col-md
**Code:**
```java
public int carFleet(int target, int[] position, int[] speed) {
    int n = position.length;
    int[][] cars = new int[n][2];
    for (int i = 0; i < n; i++) cars[i] = new int[]{position[i], speed[i]};
    Arrays.sort(cars, (a, b) -> b[0] - a[0]);
    Deque<Double> stack = new ArrayDeque<>();
    for (int[] car : cars) {
        double time = (double)(target - car[0]) / car[1];
        if (stack.isEmpty() || time > stack.peek()) {
            stack.push(time);
        }
    }
    return stack.size();
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(n)

**Edge Cases:**
- Single car → 1 fleet
- All cars same speed → number of fleets = n (if positions differ)
- Car already at target → time = 0

### 91. Largest Rectangle in Histogram — #84
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Monotonic increasing stack (prev/next smaller element)** — for each bar, find nearest smaller bars on both sides to determine max width. Stack maintains indices in increasing height order.

`````col
````col-md
**Explanation:**
1. Push indices onto stack while heights are increasing
2. When height decreases, pop and calculate area:
   - Height = `heights[popped]`
   - Width = `i - stack.peek() - 1` (or `i` if stack empty)
3. After loop, pop remaining with `i = n`
4. Track max area
````

````col-md
**Code:**
```java
public int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0, n = heights.length;
    for (int i = 0; i <= n; i++) {
        int h = i == n ? 0 : heights[i];
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            int height = heights[stack.pop()];
            int width = stack.isEmpty() ? i : i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- All same height → area = height × n
- Strictly increasing → largest at the end
- Single bar → its height × 1

### 92. Sum of Subarray Minimums — #907
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Monotonic stack — contribution technique** — for each element, calculate how many subarrays it's the minimum of: `left_count × right_count × value`.

`````col
````col-md
**Explanation:**
1. For each `arr[i]`, find:
   - `left[i]`: distance to previous smaller element
   - `right[i]`: distance to next smaller-or-equal element
2. Contribution of `arr[i]` = `left[i] * right[i] * arr[i]`
3. Sum all contributions
4. Use monotonic stack for both passes
````

````col-md
**Code:**
```java
public int sumSubarrayMins(int[] arr) {
    int n = arr.length, MOD = 1_000_000_007;
    int[] left = new int[n], right = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) stack.pop();
        left[i] = stack.isEmpty() ? i + 1 : i - stack.peek();
        stack.push(i);
    }
    stack.clear();
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) stack.pop();
        right[i] = stack.isEmpty() ? n - i : stack.peek() - i;
        stack.push(i);
    }

    long sum = 0;
    for (int i = 0; i < n; i++) {
        sum = (sum + (long) left[i] * right[i] % MOD * arr[i]) % MOD;
    }
    return (int) sum;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- All same elements → use strict/non-strict inequality carefully to avoid double counting
- Single element → its value
- MOD arithmetic needed for large arrays

### 93. Maximal Rectangle — #85
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Histogram per row + Largest Rectangle in Histogram** — build a histogram for each row (height = consecutive 1s above), then apply #91 to each row.

`````col
````col-md
**Explanation:**
1. Build `heights[]` array: for each column, if cell is '1' → height++, else reset to 0
2. After updating heights for each row, apply #91 (Largest Rectangle in Histogram)
3. Track max across all rows
````

````col-md
**Code:**
```java
public int maximalRectangle(char[][] matrix) {
    if (matrix.length == 0) return 0;
    int cols = matrix[0].length, maxArea = 0;
    int[] heights = new int[cols];
    for (char[] row : matrix) {
        for (int j = 0; j < cols; j++) {
            heights[j] = row[j] == '1' ? heights[j] + 1 : 0;
        }
        maxArea = Math.max(maxArea, largestRectangleArea(heights));
    }
    return maxArea;
}

private int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();
    int max = 0, n = heights.length;
    for (int i = 0; i <= n; i++) {
        int h = i == n ? 0 : heights[i];
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            int height = heights[stack.pop()];
            int width = stack.isEmpty() ? i : i - stack.peek() - 1;
            max = Math.max(max, height * width);
        }
        stack.push(i);
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(rows × cols) | Space: O(cols)

**Edge Cases:**
- All zeros → 0
- All ones → rows × cols
- Single row/column

### 94. Evaluate Reverse Polish Notation — #150
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Stack-based RPN evaluation** — push numbers, pop two on operator, compute, push result. Clean and mechanical.

`````col
````col-md
**Explanation:**
1. For each token:
   - If number → push to stack
   - If operator → pop `b`, pop `a`, compute `a op b`, push result
2. Final stack value = answer
````

````col-md
**Code:**
```java
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (String t : tokens) {
        switch (t) {
            case "+" -> stack.push(stack.pop() + stack.pop());
            case "-" -> { int b = stack.pop(); stack.push(stack.pop() - b); }
            case "*" -> stack.push(stack.pop() * stack.pop());
            case "/" -> { int b = stack.pop(); stack.push(stack.pop() / b); }
            default -> stack.push(Integer.parseInt(t));
        }
    }
    return stack.pop();
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Single number → result is that number
- Division truncates toward zero (Java default for int division)
- Negative numbers as tokens

### 95. Basic Calculator II — #227
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Stack with operator precedence (no parentheses)** — on `+/-` push to stack; on `*//` pop, compute, push result. Final sum of stack = answer.

`````col
````col-md
**Explanation:**
1. Track current number and previous operator
2. When operator encountered (or end of string):
   - If prev op was `+` → push num
   - If prev op was `-` → push -num
   - If prev op was `*` → pop, multiply, push
   - If prev op was `/` → pop, divide, push
3. Sum everything in stack
````

````col-md
**Code:**
```java
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int num = 0;
    char op = '+';
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (Character.isDigit(c)) num = num * 10 + (c - '0');
        if ((!Character.isDigit(c) && c != ' ') || i == s.length() - 1) {
            switch (op) {
                case '+' -> stack.push(num);
                case '-' -> stack.push(-num);
                case '*' -> stack.push(stack.pop() * num);
                case '/' -> stack.push(stack.pop() / num);
            }
            op = c;
            num = 0;
        }
    }
    int result = 0;
    for (int n : stack) result += n;
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Spaces between characters → skip
- Single number → return it
- Leading/trailing spaces

### 96. Decode String — #394
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Two stacks (count stack + string stack) for nested decoding** — on `[`, push current string and count; on `]`, pop and build `prev + current.repeat(count)`.

`````col
````col-md
**Explanation:**
1. Scan character by character:
   - Digit → build multi-digit number
   - `[` → push current string and count onto stacks, reset both
   - `]` → pop count and prev string, result = prev + current.repeat(count)
   - Letter → append to current string
2. Return final current string
````

````col-md
**Code:**
```java
public String decodeString(String s) {
    Deque<Integer> countStack = new ArrayDeque<>();
    Deque<StringBuilder> strStack = new ArrayDeque<>();
    StringBuilder current = new StringBuilder();
    int num = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '[') {
            countStack.push(num);
            strStack.push(current);
            current = new StringBuilder();
            num = 0;
        } else if (c == ']') {
            int count = countStack.pop();
            StringBuilder prev = strStack.pop();
            prev.append(current.toString().repeat(count));
            current = prev;
        } else {
            current.append(c);
        }
    }
    return current.toString();
}
```
````
`````

**Complexity:** Time: O(output length) | Space: O(output length)

**Edge Cases:**
- Nested encoding: "2[a3[b]]" → "abbbabbb"
- Multi-digit numbers: "100[a]"
- No encoding → return string as-is
