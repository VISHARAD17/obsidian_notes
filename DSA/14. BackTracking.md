### 213. Subsets — #78
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking — generate power set** — at each index: include or exclude. The `dfs(i+1)` with add/remove is the universal backtracking skeleton.

`````col
````col-md
**Explanation:**
1. Start with empty list, index 0
2. At each index: add to result, then:
   - Include nums[i], recurse with i+1
   - Backtrack (remove last)
3. Continue until index == n
````

````col-md
**Code:**
```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrack(nums, i + 1, path, result);
        path.removeLast();
    }
}
```
````
`````

**Complexity:** Time: O(n × 2^n) | Space: O(n)

**Edge Cases:**
- Empty array → [[]]
- Single element → [[], [elem]]

### 214. Subsets II — #90
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking with deduplication at same recursion level** — sort first. Skip `nums[i]` if `nums[i] == nums[i-1]` and `i > start` (same level duplicate).

`````col
````col-md
**Explanation:**
1. Sort the array
2. Same backtracking as #213
3. Add dedup: `if (i > start && nums[i] == nums[i-1]) continue`
4. This skips choosing the same value twice at the same decision level
````

````col-md
**Code:**
```java
public List<List<Integer>> subsetsWithDup(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i - 1]) continue;
        path.add(nums[i]);
        backtrack(nums, i + 1, path, result);
        path.removeLast();
    }
}
```
````
`````

**Complexity:** Time: O(n × 2^n) | Space: O(n)

**Edge Cases:**
- All duplicates [1,1,1] → [[], [1], [1,1], [1,1,1]]

### 215. Permutations — #46
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking with `boolean[] used`** — order matters, so use `used[]` instead of start index. Each position can pick any unused element.

`````col
````col-md
**Explanation:**
1. For each position: try all unused elements
2. Mark used, recurse, unmark (backtrack)
3. When path length == n → add to result
````

````col-md
**Code:**
```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, new boolean[nums.length], new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) { result.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, result);
        path.removeLast();
        used[i] = false;
    }
}
```
````
`````

**Complexity:** Time: O(n × n!) | Space: O(n)

**Edge Cases:**
- Single element → [[elem]]
- Two elements → [[a,b], [b,a]]

### 216. Permutations II — #47
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking with deduplication for permutations** — sort + skip if `used[i]` OR `(i>0 && nums[i]==nums[i-1] && !used[i-1])`. The `!used[i-1]` ensures we only use duplicates in order.

`````col
````col-md
**Explanation:**
1. Sort array
2. Same as #215 but add: skip if same as previous AND previous not used
3. This prevents generating duplicate permutations
````

````col-md
**Code:**
```java
public List<List<Integer>> permuteUnique(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, new boolean[nums.length], new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) { result.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, result);
        path.removeLast();
        used[i] = false;
    }
}
```
````
`````

**Complexity:** Time: O(n × n!) | Space: O(n)

**Edge Cases:**
- All same elements → single permutation
- Two duplicates → dedup cuts half the work

### 217. Combination Sum — #39
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking — unlimited reuse (pass i, not i+1)** — passing `i` (not `i+1`) allows reusing the same element. Continue until sum ≥ target.

`````col
````col-md
**Explanation:**
1. Sort candidates (optional, for early termination)
2. Backtrack: include candidates[i], recurse with same `i` (reuse)
3. If remaining == 0 → add to result
4. If remaining < 0 → prune
````

````col-md
**Code:**
```java
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(candidates);
    backtrack(candidates, target, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int remain, int start, List<Integer> path, List<List<Integer>> result) {
    if (remain == 0) { result.add(new ArrayList<>(path)); return; }
    for (int i = start; i < nums.length && nums[i] <= remain; i++) {
        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i, path, result); // i, not i+1
        path.removeLast();
    }
}
```
````
`````

**Complexity:** Time: O(n^(target/min)) | Space: O(target/min)

**Edge Cases:**
- Single candidate equals target → [[candidate]]
- Target = 0 → [[]] (empty combination)

### 218. Combination Sum II — #40
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking — no reuse + deduplication** — pass `i+1` (no reuse) + sort + same dedup as #214 (`i > start && nums[i] == nums[i-1]`).

`````col
````col-md
**Explanation:**
1. Sort candidates
2. Recurse with `i+1` (no reuse)
3. Dedup: skip if `i > start && candidates[i] == candidates[i-1]`
4. Prune: if `candidates[i] > remain` → break
````

````col-md
**Code:**
```java
public List<List<Integer>> combinationSum2(int[] candidates, int target) {
    Arrays.sort(candidates);
    List<List<Integer>> result = new ArrayList<>();
    backtrack(candidates, target, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int remain, int start, List<Integer> path, List<List<Integer>> result) {
    if (remain == 0) { result.add(new ArrayList<>(path)); return; }
    for (int i = start; i < nums.length && nums[i] <= remain; i++) {
        if (i > start && nums[i] == nums[i-1]) continue;
        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i + 1, path, result);
        path.removeLast();
    }
}
```
````
`````

**Complexity:** Time: O(2^n) | Space: O(n)

**Edge Cases:**
- Duplicates in input → dedup handles them
- No valid combination → empty result

### 219. Palindrome Partitioning — #131
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking with palindrome check** — at each position, try all suffixes that are palindromes. If valid, recurse on remainder.

`````col
````col-md
**Explanation:**
1. From current index, try all substrings ending at j
2. If substring [start..j] is palindrome → add to path, recurse from j+1
3. Backtrack
4. When start reaches end → add path to result
````

````col-md
**Code:**
```java
public List<List<String>> partition(String s) {
    List<List<String>> result = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(String s, int start, List<String> path, List<List<String>> result) {
    if (start == s.length()) { result.add(new ArrayList<>(path)); return; }
    for (int end = start; end < s.length(); end++) {
        if (isPalin(s, start, end)) {
            path.add(s.substring(start, end + 1));
            backtrack(s, end + 1, path, result);
            path.removeLast();
        }
    }
}

private boolean isPalin(String s, int l, int r) {
    while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
    return true;
}
```
````
`````

**Complexity:** Time: O(n × 2^n) | Space: O(n)

**Edge Cases:**
- Single char → always palindrome → [["a"]]
- Already palindrome → one partition of full string

### 220. Word Search — #79
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking on 2D grid (temp mark visited)** — mark `board[r][c] = '#'` before recursing, restore after. Cleaner than separate visited matrix.

`````col
````col-md
**Explanation:**
1. For each cell matching word[0], start DFS
2. Mark cell as visited (change to '#')
3. Explore 4 directions for next char
4. Restore cell on backtrack
5. If all chars matched → true
````

````col-md
**Code:**
```java
public boolean exist(char[][] board, String word) {
    for (int i = 0; i < board.length; i++)
        for (int j = 0; j < board[0].length; j++)
            if (dfs(board, word, i, j, 0)) return true;
    return false;
}

private boolean dfs(char[][] board, String word, int r, int c, int idx) {
    if (idx == word.length()) return true;
    if (r < 0 || r >= board.length || c < 0 || c >= board[0].length || board[r][c] != word.charAt(idx)) return false;
    char tmp = board[r][c];
    board[r][c] = '#';
    boolean found = dfs(board, word, r+1, c, idx+1) || dfs(board, word, r-1, c, idx+1)
                 || dfs(board, word, r, c+1, idx+1) || dfs(board, word, r, c-1, idx+1);
    board[r][c] = tmp;
    return found;
}
```
````
`````

**Complexity:** Time: O(m × n × 4^L) | Space: O(L) recursion depth

**Edge Cases:**
- Single cell matches single char word → true
- Word longer than total cells → false
- Same char used twice (not allowed)

### 221. N-Queens — #51
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Backtracking with 3 constraint sets (cols, diag1, diag2)** — place queens row by row. Track attacked columns and both diagonal directions in sets for O(1) check.

`````col
````col-md
**Explanation:**
1. Place one queen per row
2. For each column: check if column, diag1 (r-c), diag2 (r+c) are free
3. If free → place, add constraints, recurse to next row
4. Backtrack: remove constraints
5. When all rows filled → add board configuration
````

````col-md
**Code:**
```java
public List<List<String>> solveNQueens(int n) {
    List<List<String>> result = new ArrayList<>();
    backtrack(n, 0, new HashSet<>(), new HashSet<>(), new HashSet<>(), new int[n], result);
    return result;
}

private void backtrack(int n, int row, Set<Integer> cols, Set<Integer> d1, Set<Integer> d2, int[] queens, List<List<String>> result) {
    if (row == n) {
        List<String> board = new ArrayList<>();
        for (int q : queens) { char[] r = new char[n]; Arrays.fill(r, '.'); r[q] = 'Q'; board.add(new String(r)); }
        result.add(board);
        return;
    }
    for (int col = 0; col < n; col++) {
        if (cols.contains(col) || d1.contains(row-col) || d2.contains(row+col)) continue;
        queens[row] = col;
        cols.add(col); d1.add(row-col); d2.add(row+col);
        backtrack(n, row+1, cols, d1, d2, queens, result);
        cols.remove(col); d1.remove(row-col); d2.remove(row+col);
    }
}
```
````
`````

**Complexity:** Time: O(n!) | Space: O(n)

**Edge Cases:**
- n = 1 → [["Q"]]
- n = 2, 3 → no solution
- n = 4 → 2 solutions

### 222. Letter Combinations of a Phone Number — #17
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking on a decision map** — each digit maps to 3-4 characters. At each position, try all mapped chars.

`````col
````col-md
**Explanation:**
1. Map each digit to its characters ("2"→"abc", etc.)
2. Backtrack: for each digit in input, try all its characters
3. When path length == digits length → add to result
````

````col-md
**Code:**
```java
private static final String[] MAP = {"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};

public List<String> letterCombinations(String digits) {
    List<String> result = new ArrayList<>();
    if (digits.isEmpty()) return result;
    backtrack(digits, 0, new StringBuilder(), result);
    return result;
}

private void backtrack(String digits, int idx, StringBuilder path, List<String> result) {
    if (idx == digits.length()) { result.add(path.toString()); return; }
    for (char c : MAP[digits.charAt(idx) - '0'].toCharArray()) {
        path.append(c);
        backtrack(digits, idx + 1, path, result);
        path.deleteCharAt(path.length() - 1);
    }
}
```
````
`````

**Complexity:** Time: O(4^n) where n = digits length | Space: O(n)

**Edge Cases:**
- Empty input → empty list
- Single digit → list of its mapped chars

### 223. Generate Parentheses — #22
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Backtracking with open/close count constraints** — add '(' if open < n; add ')' if close < open. Guarantees validity without post-filtering.

`````col
````col-md
**Explanation:**
1. Track `open` and `close` counts
2. If `open < n` → can add '('
3. If `close < open` → can add ')'
4. When length == 2n → add to result
5. No invalid states possible with these constraints
````

````col-md
**Code:**
```java
public List<String> generateParenthesis(int n) {
    List<String> result = new ArrayList<>();
    backtrack(n, 0, 0, new StringBuilder(), result);
    return result;
}

private void backtrack(int n, int open, int close, StringBuilder path, List<String> result) {
    if (path.length() == 2 * n) { result.add(path.toString()); return; }
    if (open < n) {
        path.append('(');
        backtrack(n, open + 1, close, path, result);
        path.deleteCharAt(path.length() - 1);
    }
    if (close < open) {
        path.append(')');
        backtrack(n, open, close + 1, path, result);
        path.deleteCharAt(path.length() - 1);
    }
}
```
````
`````

**Complexity:** Time: O(4^n / √n) — Catalan number | Space: O(n)

**Edge Cases:**
- n = 1 → ["()"]
- n = 0 → [""]
