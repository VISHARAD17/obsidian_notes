### 97. Implement Queue using Stacks — #232
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Amortized O(1) queue via lazy transfer** — two stacks: inbox and outbox. Pour from inbox to outbox only when outbox is empty. Total pours = total pushes → amortized O(1).

`````col
````col-md
**Explanation:**
1. `push`: always push to inbox
2. `pop/peek`: if outbox empty, pour all from inbox to outbox (reverses order)
3. Pop/peek from outbox
4. Each element is moved at most twice → amortized O(1)
````

````col-md
**Code:**
```java
class MyQueue {
    Deque<Integer> inbox = new ArrayDeque<>();
    Deque<Integer> outbox = new ArrayDeque<>();

    public void push(int x) { inbox.push(x); }

    public int pop() { transfer(); return outbox.pop(); }
    public int peek() { transfer(); return outbox.peek(); }
    public boolean empty() { return inbox.isEmpty() && outbox.isEmpty(); }

    private void transfer() {
        if (outbox.isEmpty()) {
            while (!inbox.isEmpty()) outbox.push(inbox.pop());
        }
    }
}
```
````
`````

**Complexity:** Time: Amortized O(1) per operation | Space: O(n)

**Edge Cases:**
- Multiple pops without push → outbox drains
- Alternating push/pop → still amortized O(1)

### 98. Design Circular Queue — #622
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Circular buffer with head/tail and modular arithmetic** — `(tail + 1) % capacity` for circular indexing. Fixed-size array with front/rear pointers.

`````col
````col-md
**Explanation:**
1. Array of fixed size, `front = 0`, `rear = -1`, `size = 0`
2. `enqueue`: `rear = (rear + 1) % capacity`, place element
3. `dequeue`: `front = (front + 1) % capacity`
4. Full: `size == capacity`; Empty: `size == 0`
````

````col-md
**Code:**
```java
class MyCircularQueue {
    int[] data;
    int front = 0, rear = -1, size = 0, cap;

    public MyCircularQueue(int k) { data = new int[k]; cap = k; }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        rear = (rear + 1) % cap;
        data[rear] = value;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        size--;
        return true;
    }

    public int Front() { return isEmpty() ? -1 : data[front]; }
    public int Rear() { return isEmpty() ? -1 : data[rear]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == cap; }
}
```
````
`````

**Complexity:** Time: O(1) per operation | Space: O(k)

**Edge Cases:**
- Enqueue when full → return false
- Dequeue when empty → return false
- Wrap-around: rear goes from end back to 0

### 99. Sliding Window Maximum — #239 (Deque perspective)
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Monotonic decreasing deque** — (Same as #29.) Deque front = window max. Remove expired from front; remove smaller from back before adding. O(n) for all window maxima.

`````col
````col-md
**Explanation:**
1. Deque stores indices in decreasing value order
2. For each `i`:
   - Remove front if outside window
   - Remove back while `nums[back] <= nums[i]`
   - Add `i` to back
   - If `i >= k-1`: front = current window max
````

````col-md
**Code:**
```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> dq = new ArrayDeque<>();
    int[] result = new int[nums.length - k + 1];
    for (int i = 0; i < nums.length; i++) {
        while (!dq.isEmpty() && dq.peekFirst() < i - k + 1)
            dq.pollFirst();
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i])
            dq.pollLast();
        dq.offerLast(i);
        if (i >= k - 1) result[i - k + 1] = nums[dq.peekFirst()];
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(k)

**Edge Cases:**
- k == 1 → output = input
- k == n → single max value
- All equal → all results are that value

### 100. Jump Game VI — #1696
**Difficulty:** Medium

**Pattern & Key Insight:**
- **DP + Monotonic Deque for window max** — `dp[i] = nums[i] + max(dp[i-k..i-1])`. Naive DP is O(nk); deque maintains window max for O(n) total.

`````col
````col-md
**Explanation:**
1. `dp[0] = nums[0]`
2. For each `i`, we need max of `dp[i-k..i-1]`
3. Monotonic deque (decreasing dp values) gives this in O(1)
4. Remove expired indices from front
5. `dp[i] = nums[i] + dp[deque.front]`
6. Maintain deque (remove back while `dp[back] <= dp[i]`)
````

````col-md
**Code:**
```java
public int maxResult(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    Deque<Integer> dq = new ArrayDeque<>();
    dq.offer(0);
    for (int i = 1; i < n; i++) {
        while (!dq.isEmpty() && dq.peekFirst() < i - k)
            dq.pollFirst();
        dp[i] = nums[i] + dp[dq.peekFirst()];
        while (!dq.isEmpty() && dp[dq.peekLast()] <= dp[i])
            dq.pollLast();
        dq.offerLast(i);
    }
    return dp[n - 1];
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- k >= n → dp[n-1] = max(dp[0..n-2]) + nums[n-1]
- All negative → still picks best path
- k = 1 → must visit every element
