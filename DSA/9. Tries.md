### 125. Implement Trie (Prefix Tree) — #208
**Difficulty:** Medium

**Pattern & Key Insight:**
- **TrieNode with children[26] + isEnd flag** — each node has 26 children slots. Traverse/create one node per character. `isEnd` marks complete words.

`````col
````col-md
**Explanation:**
1. TrieNode: `children[26]`, `isEnd` boolean
2. Insert: traverse/create nodes for each char, mark last as `isEnd = true`
3. Search: traverse nodes; return `isEnd` at last char's node
4. StartsWith: same as search but don't check `isEnd`
````

````col-md
**Code:**
```java
class Trie {
    private Trie[] children = new Trie[26];
    private boolean isEnd;

    public void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new Trie();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        Trie node = find(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    private Trie find(String s) {
        Trie node = this;
        for (char c : s.toCharArray()) {
            node = node.children[c - 'a'];
            if (node == null) return null;
        }
        return node;
    }
}
```
````
`````

**Complexity:** Time: O(L) per operation (L = word length) | Space: O(total characters inserted)

**Edge Cases:**
- Search for word that's a prefix of another → false unless it's also inserted
- Empty string → always true for startsWith

### 126. Design Add and Search Words Data Structure — #211
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Trie + DFS for wildcard matching (`.` = any char)** — on `.`, recurse into ALL non-null children. Regular chars follow the normal trie path.

`````col
````col-md
**Explanation:**
1. Insert: same as basic Trie
2. Search: DFS with index
   - If char is `.` → try ALL 26 children recursively
   - Else → follow specific child
   - At end: check `isEnd`
````

````col-md
**Code:**
```java
class WordDictionary {
    private WordDictionary[] children = new WordDictionary[26];
    private boolean isEnd;

    public void addWord(String word) {
        WordDictionary node = this;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new WordDictionary();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        return dfs(word, 0, this);
    }

    private boolean dfs(String word, int i, WordDictionary node) {
        if (node == null) return false;
        if (i == word.length()) return node.isEnd;
        char c = word.charAt(i);
        if (c == '.') {
            for (var child : node.children)
                if (dfs(word, i + 1, child)) return true;
            return false;
        }
        return dfs(word, i + 1, node.children[c - 'a']);
    }
}
```
````
`````

**Complexity:** Time: O(26^dots × L) worst case | Space: O(total characters)

**Edge Cases:**
- All dots "..." → searches entire trie
- No wildcards → same as basic trie search
- "." at beginning → fans out immediately

### 127. Word Search II — #212
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Trie + DFS backtracking on 2D grid with pruning** — build trie from word list, then DFS from each cell. Trie prunes dead paths immediately (if no child, stop exploring).

`````col
````col-md
**Explanation:**
1. Build trie from all words
2. DFS from every cell in grid
3. At each step: check if trie has child for current char
4. If `isEnd` → found a word, add to results
5. Mark cell visited (temp modify), backtrack after
6. Prune: remove trie nodes after finding to avoid duplicates
````

````col-md
**Code:**
```java
public List<String> findWords(char[][] board, String[] words) {
    Trie root = new Trie();
    for (String w : words) root.insert(w);
    List<String> result = new ArrayList<>();
    for (int i = 0; i < board.length; i++)
        for (int j = 0; j < board[0].length; j++)
            dfs(board, i, j, root, result);
    return result;
}

private void dfs(char[][] board, int r, int c, Trie node, List<String> result) {
    if (r < 0 || r >= board.length || c < 0 || c >= board[0].length) return;
    char ch = board[r][c];
    if (ch == '#' || node.children[ch - 'a'] == null) return;
    node = node.children[ch - 'a'];
    if (node.word != null) { result.add(node.word); node.word = null; }
    board[r][c] = '#';
    dfs(board, r+1, c, node, result); dfs(board, r-1, c, node, result);
    dfs(board, r, c+1, node, result); dfs(board, r, c-1, node, result);
    board[r][c] = ch;
}

class Trie {
    Trie[] children = new Trie[26];
    String word;
    void insert(String w) {
        Trie node = this;
        for (char c : w.toCharArray()) {
            if (node.children[c-'a'] == null) node.children[c-'a'] = new Trie();
            node = node.children[c-'a'];
        }
        node.word = w;
    }
}
```
````
`````

**Complexity:** Time: O(m × n × 4^L) with trie pruning | Space: O(total word chars)

**Edge Cases:**
- Duplicate words in input → `node.word = null` after finding prevents duplicates
- Single cell board → can only find single-char words
- Words sharing prefixes → trie handles efficiently
