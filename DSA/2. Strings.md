### 30. Reverse Words in a String — #151
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Split, trim, reverse** — split by whitespace, reverse the word array. Handle multiple spaces with regex `\\s+`.

`````col
````col-md
**Explanation:**
1. Trim leading/trailing spaces
2. Split by one or more spaces (`\\s+`)
3. Reverse the resulting array
4. Join with single space
````

````col-md
**Code:**
```java
public String reverseWords(String s) {
    String[] words = s.trim().split("\\s+");
    int l = 0, r = words.length - 1;
    while (l < r) {
        String tmp = words[l];
        words[l++] = words[r];
        words[r--] = tmp;
    }
    return String.join(" ", words);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Multiple spaces between words → handled by `\\s+`
- Single word → returned as-is

### 31. Longest Common Prefix — #14
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Vertical scanning** — compare characters column by column across all strings. Stop at first mismatch.

`````col
````col-md
**Explanation:**
1. Take first string as reference
2. For each char position `i`:
   - Compare `strs[0].charAt(i)` with all other strings
   - If mismatch or out of bounds → return prefix so far
3. Return entire first string if no mismatch
````

````col-md
**Code:**
```java
public String longestCommonPrefix(String[] strs) {
    if (strs.length == 0) return "";
    for (int i = 0; i < strs[0].length(); i++) {
        char c = strs[0].charAt(i);
        for (int j = 1; j < strs.length; j++) {
            if (i >= strs[j].length() || strs[j].charAt(i) != c) {
                return strs[0].substring(0, i);
            }
        }
    }
    return strs[0];
}
```
````
`````

**Complexity:** Time: O(S) where S = sum of all chars | Space: O(1)

**Edge Cases:**
- Empty array → ""
- Array with empty string → ""
- All strings identical → return that string

### 32. String to Integer (atoi) — #8
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Deterministic parser / state machine** — handle whitespace → sign → digits → overflow. Check overflow BEFORE multiplying.

`````col
````col-md
**Explanation:**
1. Skip leading whitespace
2. Handle optional sign (+/-)
3. Parse digits: `result = result * 10 + digit`
4. Overflow check: if `result > MAX/10` or `result == MAX/10 && digit > 7` → clamp
5. Apply sign and return
````

````col-md
**Code:**
```java
public int myAtoi(String s) {
    int i = 0, n = s.length(), sign = 1, result = 0;
    while (i < n && s.charAt(i) == ' ') i++;
    if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
        sign = s.charAt(i++) == '-' ? -1 : 1;
    }
    while (i < n && Character.isDigit(s.charAt(i))) {
        int digit = s.charAt(i++) - '0';
        if (result > Integer.MAX_VALUE / 10 ||
            (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
        }
        result = result * 10 + digit;
    }
    return result * sign;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Leading whitespace + sign → "   -42"
- Overflow → clamp to INT_MAX/INT_MIN
- Non-digit after digits → stop parsing

### 33. Roman to Integer — #13
**Difficulty:** Easy

**Pattern & Key Insight:**
- **HashMap lookup + lookahead rule** — if current value < next value, subtract it; otherwise add it.

`````col
````col-md
**Explanation:**
1. Map each Roman char to its value
2. Scan left to right
3. If `val[i] < val[i+1]` → subtract `val[i]`
4. Else → add `val[i]`
````

````col-md
**Code:**
```java
public int romanToInt(String s) {
    Map<Character, Integer> map = Map.of(
        'I',1,'V',5,'X',10,'L',50,
        'C',100,'D',500,'M',1000);
    int result = 0;
    for (int i = 0; i < s.length(); i++) {
        int val = map.get(s.charAt(i));
        if (i + 1 < s.length() && val < map.get(s.charAt(i + 1))) {
            result -= val;
        } else {
            result += val;
        }
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Subtractive cases: IV=4, IX=9, XL=40, XC=90, CD=400, CM=900
- Single character → just its value

### 34. Zigzag Conversion — #6
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Index simulation with direction flag** — assign each character to a row using a bouncing index (0→numRows-1→0→...).

`````col
````col-md
**Explanation:**
1. Create `numRows` StringBuilder rows
2. Traverse string, assign char to current row
3. Flip direction at row 0 and row `numRows-1`
4. Concatenate all rows
````

````col-md
**Code:**
```java
public String convert(String s, int numRows) {
    if (numRows == 1) return s;
    StringBuilder[] rows = new StringBuilder[numRows];
    for (int i = 0; i < numRows; i++) rows[i] = new StringBuilder();
    int row = 0, dir = -1;
    for (char c : s.toCharArray()) {
        rows[row].append(c);
        if (row == 0 || row == numRows - 1) dir = -dir;
        row += dir;
    }
    StringBuilder result = new StringBuilder();
    for (var sb : rows) result.append(sb);
    return result.toString();
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- numRows == 1 → return original string
- numRows >= s.length() → each row has at most 1 char

### 35. Count and Say — #38
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Iterative string generation (run-length encoding)** — build each term by describing consecutive groups of the previous term.

`````col
````col-md
**Explanation:**
1. Start with "1"
2. For each iteration, scan previous string
3. Count consecutive same characters
4. Append `count + char` to build next string
5. Repeat `n-1` times
````

````col-md
**Code:**
```java
public String countAndSay(int n) {
    String s = "1";
    for (int i = 1; i < n; i++) {
        StringBuilder sb = new StringBuilder();
        int count = 1;
        for (int j = 1; j < s.length(); j++) {
            if (s.charAt(j) == s.charAt(j - 1)) count++;
            else { sb.append(count).append(s.charAt(j - 1)); count = 1; }
        }
        sb.append(count).append(s.charAt(s.length() - 1));
        s = sb.toString();
    }
    return s;
}
```
````
`````

**Complexity:** Time: O(2^n) worst case (string grows exponentially) | Space: O(2^n)

**Edge Cases:**
- n = 1 → "1"
- n = 2 → "11" (one 1)

### 36. Valid Palindrome — #125
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Two pointers + character filtering** — skip non-alphanumeric chars, compare from both ends case-insensitively.

`````col
````col-md
**Explanation:**
1. `l = 0`, `r = n-1`
2. Skip non-alphanumeric from left and right
3. Compare lowercase chars
4. If mismatch → false
5. If pointers cross → true
````

````col-md
**Code:**
```java
public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) !=
            Character.toLowerCase(s.charAt(r))) return false;
        l++; r--;
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Empty string → true
- Only non-alphanumeric chars → true
- Mixed case: "RaceCar" → true

### 37. Longest Palindromic Substring — #5
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Expand-around-center** — for each center (both odd and even length), expand outward while chars match. Track the longest.

`````col
````col-md
**Explanation:**
1. For each index `i`, expand from center:
   - Odd length: center = `(i, i)`
   - Even length: center = `(i, i+1)`
2. Expand while `s[l] == s[r]`
3. Track longest palindrome's start and length
````

````col-md
**Code:**
```java
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);
        int len2 = expand(s, i, i + 1);
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

private int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--; r++;
    }
    return r - l - 1;
}
```
````
`````

**Complexity:** Time: O(n²) | Space: O(1)

**Edge Cases:**
- Single char → itself
- All same chars → entire string
- No palindrome longer than 1 → return first char

### 38. Palindromic Substrings — #647
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Expand-around-center, count all** — same as #5 but count every valid expansion step instead of tracking longest.

`````col
````col-md
**Explanation:**
1. For each center (odd and even)
2. Expand while palindrome condition holds
3. Each valid expansion = one more palindromic substring
4. Sum all counts
````

````col-md
**Code:**
```java
public int countSubstrings(String s) {
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        count += expand(s, i, i);
        count += expand(s, i, i + 1);
    }
    return count;
}

private int expand(String s, int l, int r) {
    int count = 0;
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        count++; l--; r++;
    }
    return count;
}
```
````
`````

**Complexity:** Time: O(n²) | Space: O(1)

**Edge Cases:**
- Single char → count = 1
- "aaa" → 6 (a,a,a,aa,aa,aaa)

### 39. Valid Palindrome II — #680
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Two pointers + one allowed deletion** — on mismatch, try skipping left OR right and check if either remaining substring is a palindrome.

`````col
````col-md
**Explanation:**
1. Two pointers `l`, `r` from both ends
2. On mismatch: check `isPalin(l+1, r)` OR `isPalin(l, r-1)`
3. If either works → true
4. If no mismatch → true
````

````col-md
**Code:**
```java
public boolean validPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        if (s.charAt(l) != s.charAt(r)) {
            return isPalin(s, l + 1, r) || isPalin(s, l, r - 1);
        }
        l++; r--;
    }
    return true;
}

private boolean isPalin(String s, int l, int r) {
    while (l < r) {
        if (s.charAt(l++) != s.charAt(r--)) return false;
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Already a palindrome → true without deletion
- Need to delete first or last char

### 40. Encode and Decode Strings — #271
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Length-prefix protocol (len#string)** — encode each string as `length + "#" + string`. Delimiter-safe because length tells you exactly how many chars to read.

`````col
````col-md
**Explanation:**
1. Encode: for each string, prepend `str.length() + "#"`
2. Decode: read number until `#`, extract next `len` chars
3. No delimiter collision possible
````

````col-md
**Code:**
```java
public String encode(List<String> strs) {
    StringBuilder sb = new StringBuilder();
    for (String s : strs) sb.append(s.length()).append('#').append(s);
    return sb.toString();
}

public List<String> decode(String s) {
    List<String> result = new ArrayList<>();
    int i = 0;
    while (i < s.length()) {
        int hash = s.indexOf('#', i);
        int len = Integer.parseInt(s.substring(i, hash));
        result.add(s.substring(hash + 1, hash + 1 + len));
        i = hash + 1 + len;
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Empty strings in list → encoded as "0#"
- Strings containing "#" → safe due to length prefix

### 41. Find the Index of the First Occurrence in a String — #28
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Sliding window string match** — check each window of size `needle.length` in haystack. Brute force O(n×m) but sufficient for interviews.

`````col
````col-md
**Explanation:**
1. For each starting index `i` in haystack (up to `n - m`)
2. Compare substring of length `m` with needle
3. If match → return `i`
4. No match found → return -1
````

````col-md
**Code:**
```java
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    for (int i = 0; i <= n - m; i++) {
        if (haystack.substring(i, i + m).equals(needle)) {
            return i;
        }
    }
    return -1;
}
```
````
`````

**Complexity:** Time: O(n × m) | Space: O(m) for substring

**Edge Cases:**
- Empty needle → return 0
- Needle longer than haystack → -1
- Needle at the very end

### 43. Group Anagrams — #49
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap with canonical key (sorted string)** — two strings are anagrams iff their sorted versions are equal. Group by sorted key.

`````col
````col-md
**Explanation:**
1. For each string, sort its characters → canonical key
2. Use HashMap<String, List<String>>
3. Group strings with same key
4. Return all values
````

````col-md
**Code:**
```java
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```
````
`````

**Complexity:** Time: O(n × k log k) where k = max string length | Space: O(n × k)

**Edge Cases:**
- Empty strings → all group together (key = "")
- Single char strings → each unique char is its own group

### 44. Rabin-Karp (Rolling Hash) — #28 (Advanced)
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Rolling hash for O(n) average substring search** — compute hash of window, slide by removing left char's contribution and adding right. Compare hashes to avoid O(m) string compare.

`````col
````col-md
**Explanation:**
1. Compute hash of needle
2. Compute hash of first window in haystack
3. Slide window: `hash = (hash - left * base^(m-1)) * base + right`
4. On hash match, verify with actual string compare (avoid collisions)
````

````col-md
**Code:**
```java
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m > n) return -1;
    long base = 26, mod = 1_000_000_007;
    long power = 1, hHash = 0, nHash = 0;
    for (int i = 0; i < m - 1; i++) power = power * base % mod;
    for (int i = 0; i < m; i++) {
        nHash = (nHash * base + needle.charAt(i)) % mod;
        hHash = (hHash * base + haystack.charAt(i)) % mod;
    }
    for (int i = 0; i <= n - m; i++) {
        if (hHash == nHash && haystack.substring(i, i + m).equals(needle))
            return i;
        if (i < n - m) {
            hHash = ((hHash - haystack.charAt(i) * power % mod + mod)
                     * base + haystack.charAt(i + m)) % mod;
        }
    }
    return -1;
}
```
````
`````

**Complexity:** Time: O(n) average, O(n×m) worst (hash collisions) | Space: O(1)

**Edge Cases:**
- Hash collision → string comparison as fallback
- All same characters → worst case for simple hash
