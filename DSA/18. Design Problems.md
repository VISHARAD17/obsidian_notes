### 240. Design Twitter — #355
**Difficulty:** Medium

**Pattern & Key Insight:**
- **HashMap + PriorityQueue + OOP design** — merge-K-sorted-lists for news feed. HashMap for follow relationships. Each user has a tweet list with timestamps.

`````col
````col-md
**Explanation:**
1. `Map<userId, Set<followeeId>>` for follows
2. `Map<userId, List<Tweet>>` for tweets (with timestamp)
3. `getNewsFeed`: merge latest 10 tweets from user + all followees using max-heap
4. Each user follows themselves by default
````

````col-md
**Code:**
```java
class Twitter {
    Map<Integer, Set<Integer>> follows = new HashMap<>();
    Map<Integer, List<int[]>> tweets = new HashMap<>();
    int time = 0;

    public void postTweet(int userId, int tweetId) {
        tweets.computeIfAbsent(userId, k -> new ArrayList<>()).add(new int[]{time++, tweetId});
    }

    public List<Integer> getNewsFeed(int userId) {
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        Set<Integer> users = follows.getOrDefault(userId, new HashSet<>());
        users.add(userId);
        for (int uid : users) {
            List<int[]> t = tweets.getOrDefault(uid, List.of());
            for (int i = t.size() - 1; i >= Math.max(0, t.size() - 10); i--)
                pq.offer(t.get(i));
        }
        List<Integer> feed = new ArrayList<>();
        while (!pq.isEmpty() && feed.size() < 10) feed.add(pq.poll()[1]);
        return feed;
    }

    public void follow(int followerId, int followeeId) {
        follows.computeIfAbsent(followerId, k -> new HashSet<>()).add(followeeId);
    }

    public void unfollow(int followerId, int followeeId) {
        if (follows.containsKey(followerId)) follows.get(followerId).remove(followeeId);
    }
}
```
````
`````

**Complexity:** Time: O(F × T × log(10)) for getNewsFeed where F = followees, T = tweets per user | Space: O(users × tweets)

**Edge Cases:**
- User unfollows then follows again
- User with no tweets → empty feed
- User follows themselves (implicit)

### 241. Design HashMap — #706
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Array of buckets + linked list chaining** — hash function maps key to bucket index. Collision handling via chaining (linked list per bucket).

`````col
````col-md
**Explanation:**
1. Array of `size` buckets (e.g., 10007 — prime)
2. Hash function: `key % size`
3. Each bucket: linked list of (key, value) pairs
4. Put: find bucket, search for key, update or append
5. Get/Remove: find bucket, search for key
````

````col-md
**Code:**
```java
class MyHashMap {
    private static final int SIZE = 10007;
    List<int[]>[] buckets;

    public MyHashMap() {
        buckets = new List[SIZE];
    }

    public void put(int key, int value) {
        int idx = key % SIZE;
        if (buckets[idx] == null) buckets[idx] = new ArrayList<>();
        for (int[] pair : buckets[idx]) {
            if (pair[0] == key) { pair[1] = value; return; }
        }
        buckets[idx].add(new int[]{key, value});
    }

    public int get(int key) {
        int idx = key % SIZE;
        if (buckets[idx] == null) return -1;
        for (int[] pair : buckets[idx])
            if (pair[0] == key) return pair[1];
        return -1;
    }

    public void remove(int key) {
        int idx = key % SIZE;
        if (buckets[idx] == null) return;
        buckets[idx].removeIf(pair -> pair[0] == key);
    }
}
```
````
`````

**Complexity:** Time: O(1) average, O(n/buckets) worst | Space: O(n + buckets)

**Edge Cases:**
- Key doesn't exist on get → -1
- Update existing key
- Remove non-existent key → no-op
