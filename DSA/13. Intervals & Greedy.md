### 206. Meeting Rooms — #252
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Sort by start, check adjacent overlap** — if any `intervals[i].start < intervals[i-1].end` → overlap → can't attend all.

`````col
````col-md
**Explanation:**
1. Sort intervals by start time
2. For each consecutive pair: if start < previous end → overlap
3. If no overlap found → true
````

````col-md
**Code:**
```java
public boolean canAttendMeetings(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] < intervals[i - 1][1]) return false;
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(1)

**Edge Cases:**
- Empty/single interval → true
- All same time → false if more than one

### 207. Merge Intervals — #56
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Sort by start + greedy extension** — sort by start. If current overlaps with last merged, extend end. Otherwise, add as new interval.

`````col
````col-md
**Explanation:**
1. Sort by start time
2. For each interval: if overlaps with last in result → extend end
3. Else → add as new interval
4. Overlap: `current.start <= last.end`
````

````col-md
**Code:**
```java
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    List<int[]> merged = new ArrayList<>();
    for (int[] interval : intervals) {
        if (merged.isEmpty() || interval[0] > merged.getLast()[1]) {
            merged.add(interval);
        } else {
            merged.getLast()[1] = Math.max(merged.getLast()[1], interval[1]);
        }
    }
    return merged.toArray(new int[0][]);
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(n)

**Edge Cases:**
- All overlap → single merged interval
- No overlaps → return as-is
- Touching intervals [1,2],[2,3] → merge

### 208. Insert Interval — #57
**Difficulty:** Medium

**Pattern & Key Insight:**
- **3-phase scan (before / overlap / after)** — add all intervals ending before new, merge all overlapping, add all starting after.

`````col
````col-md
**Explanation:**
1. Add all intervals with end < newInterval.start
2. Merge all overlapping: update newInterval's start/end
3. Add merged newInterval
4. Add remaining intervals
````

````col-md
**Code:**
```java
public int[][] insert(int[][] intervals, int[] newInterval) {
    List<int[]> result = new ArrayList<>();
    int i = 0, n = intervals.length;
    while (i < n && intervals[i][1] < newInterval[0])
        result.add(intervals[i++]);
    while (i < n && intervals[i][0] <= newInterval[1]) {
        newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
        newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
        i++;
    }
    result.add(newInterval);
    while (i < n) result.add(intervals[i++]);
    return result.toArray(new int[0][]);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- newInterval before all → prepend
- newInterval after all → append
- newInterval covers all → single merged

### 209. Non-overlapping Intervals — #435
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Activity selection — sort by end time, greedy keep** — keep intervals finishing earliest. Count how many we can keep; removals = total - kept.

`````col
````col-md
**Explanation:**
1. Sort by end time
2. Greedily keep: if `interval.start >= lastEnd` → keep it, update lastEnd
3. Count kept intervals
4. Removals = total - kept
````

````col-md
**Code:**
```java
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
    int kept = 0, lastEnd = Integer.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] >= lastEnd) {
            kept++;
            lastEnd = interval[1];
        }
    }
    return intervals.length - kept;
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(1)

**Edge Cases:**
- No overlaps → 0 removals
- All overlap → remove n-1

### 210. Meeting Rooms II — #253
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Min-heap tracking active end times** — sort by start. For each meeting: if earliest ending room is free (end ≤ start), reuse it. Else open new room.

`````col
````col-md
**Explanation:**
1. Sort intervals by start time
2. Min-heap stores end times of active meetings
3. For each meeting: if `heap.peek() <= start` → poll (room freed)
4. Add current end time to heap
5. Heap size = rooms needed
````

````col-md
**Code:**
```java
public int minMeetingRooms(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int[] interval : intervals) {
        if (!heap.isEmpty() && heap.peek() <= interval[0]) {
            heap.poll();
        }
        heap.offer(interval[1]);
    }
    return heap.size();
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(n)

**Edge Cases:**
- All concurrent → n rooms
- Sequential (no overlap) → 1 room

### 211. Minimum Number of Arrows to Burst Balloons — #452
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Greedy — sort by end, shoot at each end** — same logic as Activity Selection. An arrow at the end of one balloon bursts all overlapping balloons.

`````col
````col-md
**Explanation:**
1. Sort by end coordinate
2. Shoot arrow at first balloon's end
3. Skip all balloons whose start ≤ arrow position (they're burst)
4. Next unbursted balloon → new arrow at its end
5. Count arrows
````

````col-md
**Code:**
```java
public int findMinArrowShots(int[][] points) {
    Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));
    int arrows = 1, arrowPos = points[0][1];
    for (int i = 1; i < points.length; i++) {
        if (points[i][0] > arrowPos) {
            arrows++;
            arrowPos = points[i][1];
        }
    }
    return arrows;
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(1)

**Edge Cases:**
- Single balloon → 1 arrow
- All overlap at one point → 1 arrow
- Use `Integer.compare` to avoid overflow with large coordinates
