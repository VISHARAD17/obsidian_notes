
- Arrays in c++ : 
	- `vector<int>a(n, 0)` array of size `n` with default value as `0`
	- multi-dimensional array `vector<vector<int>> multiDimenArr(n, vector<int>(m, 0));` matrix of size `n x m`
- Arrays in Java: 
	- `List<int> list = new ArraysList<>()`- dynamic list
	- `int [] list = new int[5]` integer array of size 5
	- multidimentional array / matrix : `int [][] matrix = new int[4][5]`
