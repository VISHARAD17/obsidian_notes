### 1. Contains Duplicate — #217
**Difficulty:** Easy

**Pattern & Key Insight:**
- **HashSet for O(1) lookup** — `set.add(x)` returns `false` on duplicate, giving one-pass detection.

`````col
````col-md
**Explanation:**
1. Iterate through the array
2. Try adding each element to a HashSet
3. If `add()` returns false → duplicate exists
4. If loop completes → no duplicates
````
````col-md
**Code:**
```java
public boolean containsDuplicate(int[] nums) {
    Set<Integer> seen = new HashSet<>();
    for (int n : nums) {
        if (!seen.add(n)) return true;
    }
    return false;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- Empty array / single element → false
- All same elements → caught at index 1

### 2. Move Zeroes — #283
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Read/Write two pointers (in-place partition)** — write pointer places non-zero elements at the front; read pointer scans everything.

`````col
````col-md
**Explanation:**
1. `write` pointer starts at 0
2. `read` pointer scans left to right
3. If `nums[read] != 0`, copy to `nums[write]` and increment `write`
4. After scan, fill remaining positions with 0
````

````col-md
**Code:**
```java
public void moveZeroes(int[] nums) {
    int write = 0;
    for (int read = 0; read < nums.length; read++) {
        if (nums[read] != 0) {
            nums[write++] = nums[read];
        }
    }
    while (write < nums.length) {
        nums[write++] = 0;
    }
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- All zeros → write stays at 0, entire array filled with 0
- No zeros → array unchanged

### 3. Find All Numbers Disappeared in an Array — #448
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Index-as-hash (negation marking)** — values are in [1,n], so use `nums[val-1]` as a marker. Negate to mark "seen." Positive indices at the end = missing numbers.

`````col
````col-md
**Explanation:**
1. For each value, mark index `|val|-1` as negative
2. After marking, scan array
3. Indices still positive → that `index+1` is missing
4. Collect all such missing numbers
````

````col-md
**Code:**
```java
public List<Integer> findDisappearedNumbers(int[] nums) {
    for (int num : nums) {
        int idx = Math.abs(num) - 1;
        if (nums[idx] > 0) nums[idx] = -nums[idx];
    }
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] > 0) result.add(i + 1);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1) (output excluded)

**Edge Cases:**
- All elements same (e.g., [1,1,1]) → all except 1 are missing
- Already complete [1..n] → empty result

### 4. Best Time to Buy and Sell Stock — #121
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Running minimum + greedy single pass** — track the lowest price seen so far; at each day, check if selling today gives a better profit.

`````col
````col-md
**Explanation:**
1. Initialize `minPrice = MAX`, `maxProfit = 0`
2. For each price:
   - Update `minPrice` if current is lower
   - Update `maxProfit` if `price - minPrice` is higher
3. Return `maxProfit`
````

````col-md
**Code:**
```java
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;
    int maxProfit = 0;
    for (int price : prices) {
        minPrice = Math.min(minPrice, price);
        maxProfit = Math.max(maxProfit, price - minPrice);
    }
    return maxProfit;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Prices always decreasing → profit = 0
- Single element → profit = 0

### 5. Maximum Subarray — #53
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Kadane's Algorithm** — at each index decide: extend the current subarray OR start fresh. `dp[i] = max(nums[i], dp[i-1] + nums[i])`.

`````col
````col-md
**Explanation:**
1. `currentSum = nums[0]`, `maxSum = nums[0]`
2. From index 1 onward:
   - `currentSum = max(nums[i], currentSum + nums[i])`
   - `maxSum = max(maxSum, currentSum)`
3. Return `maxSum`
````

````col-md
**Code:**
```java
public int maxSubArray(int[] nums) {
    int current = nums[0], max = nums[0];
    for (int i = 1; i < nums.length; i++) {
        current = Math.max(nums[i], current + nums[i]);
        max = Math.max(max, current);
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- All negative → returns the least negative (single element)
- Single element → returns it

### 6. Product of Array Except Self — #238
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Prefix product + suffix product, no division** — two passes: forward builds prefix products, backward multiplies suffix into the result.

`````col
````col-md
**Explanation:**
1. Create `result[]`, set `result[i] = product of all elements left of i` (forward pass)
2. Backward pass: maintain running `suffix` product
3. Multiply `result[i] *= suffix`, then update `suffix *= nums[i]`
4. Result holds product-except-self
````

````col-md
**Code:**
```java
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    result[0] = 1;
    for (int i = 1; i < n; i++) {
        result[i] = result[i - 1] * nums[i - 1];
    }
    int suffix = 1;
    for (int i = n - 2; i >= 0; i--) {
        suffix *= nums[i + 1];
        result[i] *= suffix;
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1) (output excluded)

**Edge Cases:**
- Contains a zero → all other products become 0 except at the zero's index
- Two zeros → all products are 0

### 7. Find the Duplicate Number — #287
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Floyd's cycle detection (array as implicit graph)** — treat `nums[i]` as a "next pointer." Since there's a duplicate, a cycle exists. Find the cycle entry point.

`````col
````col-md
**Explanation:**
1. Slow and fast both start at `nums[0]`
2. Phase 1: slow moves 1 step, fast moves 2 steps until they meet
3. Phase 2: reset slow to `nums[0]`, both move 1 step
4. They meet at the duplicate number
````

````col-md
**Code:**
```java
public int findDuplicate(int[] nums) {
    int slow = nums[0], fast = nums[0];
    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow != fast);
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[fast];
    }
    return slow;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Duplicate appears more than twice → still works (cycle exists)
- Minimum size array [1,1] → detected immediately

### 8. Maximum Product Subarray — #152
**Difficulty:** Medium

**Pattern & Key Insight:**
- **DP tracking both max and min simultaneously** — a negative × negative = positive, so track `maxSoFar` and `minSoFar` at each step.

`````col
````col-md
**Explanation:**
1. Init `maxSoFar = minSoFar = result = nums[0]`
2. For each element from index 1:
   - If `nums[i] < 0`, swap max and min (negative flips them)
   - `maxSoFar = max(nums[i], maxSoFar * nums[i])`
   - `minSoFar = min(nums[i], minSoFar * nums[i])`
   - `result = max(result, maxSoFar)`
3. Return `result`
````

````col-md
**Code:**
```java
public int maxProduct(int[] nums) {
    int max = nums[0], min = nums[0], result = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] < 0) { int tmp = max; max = min; min = tmp; }
        max = Math.max(nums[i], max * nums[i]);
        min = Math.min(nums[i], min * nums[i]);
        result = Math.max(result, max);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Contains zero → resets both max and min to 0 (or nums[i])
- Single negative → returns it if it's the only element

### 9. Rotate Array — #189
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Triple reverse trick** — reverse whole array, reverse first k, reverse the rest. Achieves O(1) space in-place rotation.

`````col
````col-md
**Explanation:**
1. Normalize: `k = k % n`
2. Reverse entire array
3. Reverse first `k` elements
4. Reverse remaining `n-k` elements
````

````col-md
**Code:**
```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}

private void reverse(int[] nums, int l, int r) {
    while (l < r) {
        int tmp = nums[l];
        nums[l++] = nums[r];
        nums[r--] = tmp;
    }
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- k = 0 or k = n → no rotation needed
- k > n → use k % n

### 10. First Missing Positive — #41
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Index-as-hash (cyclic sort / placement)** — place each number at its "correct" index (`nums[i]-1`). First index where `nums[i] != i+1` is the answer.

`````col
````col-md
**Explanation:**
1. For each index, while `nums[i]` is in [1,n] and not in its correct position, swap it to `nums[nums[i]-1]`
2. After placement pass, scan for first `i` where `nums[i] != i+1`
3. Return `i+1`; if all placed correctly, return `n+1`
````

````col-md
**Code:**
```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n; i++) {
        while (nums[i] > 0 && nums[i] <= n
               && nums[nums[i] - 1] != nums[i]) {
            int idx = nums[i] - 1;
            int tmp = nums[i]; nums[i] = nums[idx]; nums[idx] = tmp;
        }
    }
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) return i + 1;
    }
    return n + 1;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- All negatives → answer is 1
- [1,2,3,...n] → answer is n+1
- Contains duplicates → cyclic sort skips them

### 12. Range Sum Query — Immutable #303
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Precomputed prefix array → O(1) range query** — build prefix sum once, answer any range `[l,r]` as `prefix[r+1] - prefix[l]`.

`````col
````col-md
**Explanation:**
1. Build `prefix[]` of size `n+1` where `prefix[0] = 0`
2. `prefix[i] = prefix[i-1] + nums[i-1]`
3. Query `sumRange(l, r)` = `prefix[r+1] - prefix[l]`
````

````col-md
**Code:**
```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        prefix = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }

    public int sumRange(int l, int r) {
        return prefix[r + 1] - prefix[l];
    }
}
```
````
`````

**Complexity:** Time: O(1) per query, O(n) build | Space: O(n)

**Edge Cases:**
- l == r → single element sum
- Entire array range → prefix[n] - prefix[0]

### 13. Subarray Sum Equals K — #560
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Prefix sum + HashMap (sum → count)** — "have I seen `currentSum - k` before?" Each occurrence means a subarray with sum `k` exists.

`````col
````col-md
**Explanation:**
1. Maintain running `sum` and HashMap `<prefixSum, count>`
2. Initialize map with `{0: 1}` (empty prefix)
3. At each element: `sum += nums[i]`
4. If `sum - k` exists in map, add its count to result
5. Put/update current `sum` in map
````

````col-md
**Code:**
```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        count += map.getOrDefault(sum - k, 0);
        map.merge(sum, 1, Integer::sum);
    }
    return count;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- k = 0 → subarrays with sum 0 (not just empty)
- Negative numbers → prefix sum can decrease, HashMap handles it

### 14. Contiguous Array — #525
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Prefix sum with +1/-1 encoding + HashMap** — convert 0→-1. Equal 0s and 1s = subarray with sum 0 = two equal prefix sums. Store first occurrence of each prefix sum.

`````col
````col-md
**Explanation:**
1. Treat 0 as -1, compute running sum
2. HashMap stores `<sum, first_index>`
3. If same sum seen again at index `j`, subarray `[first+1, j]` has equal 0s and 1s
4. Track max length
````

````col-md
**Code:**
```java
public int findMaxLength(int[] nums) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, -1);
    int sum = 0, maxLen = 0;
    for (int i = 0; i < nums.length; i++) {
        sum += nums[i] == 1 ? 1 : -1;
        if (map.containsKey(sum)) {
            maxLen = Math.max(maxLen, i - map.get(sum));
        } else {
            map.put(sum, i);
        }
    }
    return maxLen;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- All same values → max length 0
- Entire array balanced → length = n

### 15. Minimum Size Subarray Sum — #209
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Variable sliding window (shrink when valid)** — expand right to grow sum; once sum ≥ target, shrink left to find minimum length.

`````col
````col-md
**Explanation:**
1. `left = 0`, running `sum = 0`
2. Expand `right`: add `nums[right]` to sum
3. While `sum >= target`: update min length, subtract `nums[left]`, move left
4. Return min length (or 0 if never valid)
````

````col-md
**Code:**
```java
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left++];
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- No valid subarray → return 0
- Single element ≥ target → return 1

### 16. XOR Queries of a Subarray — #1310
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Prefix XOR for O(1) range XOR queries** — `prefixXOR[i] ^ prefixXOR[j+1]` gives XOR of range `[i,j]`. Same concept as prefix sum but with XOR.

`````col
````col-md
**Explanation:**
1. Build `prefix[]` where `prefix[i+1] = prefix[i] ^ arr[i]`
2. For query `[l, r]`: answer = `prefix[r+1] ^ prefix[l]`
3. XOR cancels itself: `a ^ a = 0`
````

````col-md
**Code:**
```java
public int[] xorQueries(int[] arr, int[][] queries) {
    int n = arr.length;
    int[] prefix = new int[n + 1];
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] ^ arr[i];
    }
    int[] result = new int[queries.length];
    for (int i = 0; i < queries.length; i++) {
        result[i] = prefix[queries[i][1] + 1] ^ prefix[queries[i][0]];
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n + q) | Space: O(n)

**Edge Cases:**
- Single element query → XOR of itself
- l == r → prefix[r+1] ^ prefix[l] = arr[l]

### 17. Two Sum II — Sorted Array #167
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Opposite-end two pointers on sorted array** — if sum too small, move left; if too large, move right. Convergence guaranteed on sorted data.

`````col
````col-md
**Explanation:**
1. `left = 0`, `right = n-1`
2. Compute sum of `nums[left] + nums[right]`
3. If sum == target → return indices
4. If sum < target → left++
5. If sum > target → right--
````

````col-md
**Code:**
```java
public int[] twoSum(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int sum = nums[l] + nums[r];
        if (sum == target) return new int[]{l + 1, r + 1};
        else if (sum < target) l++;
        else r--;
    }
    return new int[]{};
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Exactly two elements → always valid pair
- Multiple valid pairs → any one is acceptable

### 18. 3Sum — #15
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Sort + fix one + two pointers + deduplication** — sort array, fix `i`, two-pointer on remainder. Skip duplicates at every level.

`````col
````col-md
**Explanation:**
1. Sort the array
2. For each `i`, skip if `nums[i] == nums[i-1]`
3. Two pointers `l = i+1`, `r = n-1`
4. If sum == 0: record, skip duplicate l and r
5. If sum < 0: l++; if sum > 0: r--
````

````col-md
**Code:**
```java
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.add(List.of(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;
                while (l < r && nums[r] == nums[r - 1]) r--;
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
```
````
`````

**Complexity:** Time: O(n²) | Space: O(1) (excluding output)

**Edge Cases:**
- All zeros [0,0,0] → one triplet [0,0,0]
- Less than 3 elements → empty

### 19. 3Sum Closest — #16
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Sort + two pointers, track closest sum** — same structure as 3Sum but track minimum `|sum - target|` instead of exact match.

`````col
````col-md
**Explanation:**
1. Sort array, init `closest = nums[0]+nums[1]+nums[2]`
2. For each `i`, two pointers `l = i+1`, `r = n-1`
3. Compute sum; update closest if `|sum-target| < |closest-target|`
4. Move `l++` if sum < target, else `r--`
````

````col-md
**Code:**
```java
public int threeSumClosest(int[] nums, int target) {
    Arrays.sort(nums);
    int closest = nums[0] + nums[1] + nums[2];
    for (int i = 0; i < nums.length - 2; i++) {
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (Math.abs(sum - target) < Math.abs(closest - target)) {
                closest = sum;
            }
            if (sum < target) l++;
            else if (sum > target) r--;
            else return sum;
        }
    }
    return closest;
}
```
````
`````

**Complexity:** Time: O(n²) | Space: O(1)

**Edge Cases:**
- Exact match exists → return target immediately
- All elements same → sum = 3 * nums[0]

### 20. Container With Most Water — #11
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Two pointers — always move the bottleneck** — water is limited by the shorter side. Moving the taller side can never help; always move the shorter one.

`````col
````col-md
**Explanation:**
1. `l = 0`, `r = n-1`
2. Area = `min(height[l], height[r]) * (r - l)`
3. Update max area
4. Move the pointer with shorter height
5. Repeat until `l >= r`
````

````col-md
**Code:**
```java
public int maxArea(int[] height) {
    int l = 0, r = height.length - 1, max = 0;
    while (l < r) {
        int area = Math.min(height[l], height[r]) * (r - l);
        max = Math.max(max, area);
        if (height[l] < height[r]) l++;
        else r--;
    }
    return max;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Two elements → single computation
- All same height → first computation is max (widest)

### 21. Trapping Rain Water — #42
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Two pointers with running max from both ends** — water at any index = `min(maxLeft, maxRight) - height[i]`. Two pointers eliminate the need for prefix/suffix arrays.

`````col
````col-md
**Explanation:**
1. `l = 0`, `r = n-1`, `leftMax = 0`, `rightMax = 0`
2. Process the smaller side:
   - If `height[l] < height[r]`: update leftMax, add `leftMax - height[l]` to water, l++
   - Else: update rightMax, add `rightMax - height[r]` to water, r--
3. Return total water
````

````col-md
**Code:**
```java
public int trap(int[] height) {
    int l = 0, r = height.length - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (l < r) {
        if (height[l] < height[r]) {
            leftMax = Math.max(leftMax, height[l]);
            water += leftMax - height[l];
            l++;
        } else {
            rightMax = Math.max(rightMax, height[r]);
            water += rightMax - height[r];
            r--;
        }
    }
    return water;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Flat array → 0 water
- Strictly increasing/decreasing → 0 water

### 22. Sort Colors — #75
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Dutch National Flag — 3-way partition** — three pointers: `low` (boundary of 0s), `mid` (scanner), `high` (boundary of 2s). One pass.

`````col
````col-md
**Explanation:**
1. `low = 0`, `mid = 0`, `high = n-1`
2. While `mid <= high`:
   - If `nums[mid] == 0`: swap with `low`, low++, mid++
   - If `nums[mid] == 1`: mid++
   - If `nums[mid] == 2`: swap with `high`, high--
````

````col-md
**Code:**
```java
public void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums, low++, mid++);
        } else if (nums[mid] == 1) {
            mid++;
        } else {
            swap(nums, mid, high--);
        }
    }
}

private void swap(int[] a, int i, int j) {
    int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Already sorted → no swaps
- All same color → no swaps

### 23. Maximum Average Subarray I — #643
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Fixed-size sliding window** — build first window of size k, then slide: subtract left, add right. Track max sum.

`````col
````col-md
**Explanation:**
1. Compute sum of first `k` elements
2. Slide: `sum = sum - nums[i-k] + nums[i]`
3. Track max sum
4. Return `maxSum / k`
````

````col-md
**Code:**
```java
public double findMaxAverage(int[] nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    int maxSum = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        maxSum = Math.max(maxSum, sum);
    }
    return (double) maxSum / k;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- k == n → only one window
- All negatives → returns least negative average

### 24. Longest Substring Without Repeating Characters — #3
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Variable sliding window + HashSet** — expand right always; shrink left when a duplicate is found. Window always contains unique characters.

`````col
````col-md
**Explanation:**
1. `left = 0`, HashSet for window chars
2. Expand `right`: if char in set, remove `nums[left]` and left++ until no duplicate
3. Add char to set
4. Update `maxLen = max(maxLen, right - left + 1)`
````

````col-md
**Code:**
```java
public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        while (set.contains(s.charAt(right))) {
            set.remove(s.charAt(left++));
        }
        set.add(s.charAt(right));
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```
`````

**Complexity:** Time: O(n) | Space: O(min(n, charset))

**Edge Cases:**
- Empty string → 0
- All same character → 1
- All unique → n

### 25. Permutation in String — #567
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Fixed window + frequency match counter** — maintain a `matches` counter instead of comparing arrays each step. Window size = len(s1).

`````col
````col-md
**Explanation:**
1. Build frequency map of s1
2. Slide window of size `s1.length` over s2
3. Maintain `matches` count (how many of 26 chars have correct frequency)
4. If matches == 26 → permutation found
````

````col-md
**Code:**
```java
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;
    int[] freq = new int[26];
    for (char c : s1.toCharArray()) freq[c - 'a']++;
    int[] window = new int[26];
    int k = s1.length();
    for (int i = 0; i < s2.length(); i++) {
        window[s2.charAt(i) - 'a']++;
        if (i >= k) window[s2.charAt(i - k) - 'a']--;
        if (Arrays.equals(freq, window)) return true;
    }
    return false;
}
`````

### 27. Longest Repeating Character Replacement — #424
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Variable window + lazy maxFreq tracking** — window is valid if `windowSize - maxFreq <= k`. Trick: never decrease `maxFreq` when shrinking (lazy update still produces correct answer).

`````col
````col-md
**Explanation:**
1. Expand right, update frequency of `s[right]`
2. Track `maxFreq` (highest char frequency in window)
3. If `windowSize - maxFreq > k`: shrink left, decrement freq
4. Update max length = `right - left + 1`
````

````col-md
**Code:**
```java
public int characterReplacement(String s, int k) {
    int[] freq = new int[26];
    int left = 0, maxFreq = 0, maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        maxFreq = Math.max(maxFreq, ++freq[s.charAt(right) - 'A']);
        if (right - left + 1 - maxFreq > k) {
            freq[s.charAt(left++) - 'A']--;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- k >= n → entire string (length n)
- All same character → length n regardless of k

### 28. Minimum Window Substring — #76
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Variable window — shrink aggressively once valid** — expand to include all required chars, then shrink to find minimum. Use `have/need` counters for O(1) validity check.

`````col
````col-md
**Explanation:**
1. Build frequency map of `t`
2. Expand `right`: update window counts, increment `have` when a char's count matches need
3. While `have == need`: update min window, shrink left
4. Return minimum window substring
````

````col-md
**Code:**
```java
public String minWindow(String s, String t) {
    int[] need = new int[128], window = new int[128];
    for (char c : t.toCharArray()) need[c]++;
    int have = 0, required = 0;
    for (int n : need) if (n > 0) required++;
    int left = 0, minLen = Integer.MAX_VALUE, start = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window[c]++;
        if (window[c] == need[c]) have++;
        while (have == required) {
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            char lc = s.charAt(left++);
            if (window[lc] == need[lc]) have--;
            window[lc]--;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1) (fixed 128 array)

**Edge Cases:**
- t longer than s → ""
- s == t → return s
- Multiple valid windows → return the first shortest

### 29. Sliding Window Maximum — #239
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Monotonic Deque (decreasing)** — deque stores indices in decreasing value order. Front = current window max. Remove expired indices from front; remove smaller values from back.

`````col
````col-md
**Explanation:**
1. Deque stores indices of candidates (decreasing order of values)
2. For each `i`:
   - Remove front if outside window (`i - k`)
   - Remove back while `nums[back] <= nums[i]`
   - Add `i` to back
   - If `i >= k-1`: `result[i-k+1] = nums[deque.front]`
````

````col-md
**Code:**
```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> dq = new ArrayDeque<>();
    int[] result = new int[nums.length - k + 1];
    for (int i = 0; i < nums.length; i++) {
        while (!dq.isEmpty() && dq.peekFirst() < i - k + 1)
            dq.pollFirst();
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i])
            dq.pollLast();
        dq.offerLast(i);
        if (i >= k - 1) result[i - k + 1] = nums[dq.peekFirst()];
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(k)

**Edge Cases:**
- k == 1 → output is same as input
- k == n → single element output (the global max)
- All elements same → all max values are equal
