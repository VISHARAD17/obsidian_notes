### 224. Single Number — #136
**Difficulty:** Easy

**Pattern & Key Insight:**
- **XOR self-cancellation (`a^a=0, a^0=a`)** — XOR all elements. Pairs cancel out, the unique element survives.

`````col
````col-md
**Explanation:**
1. XOR all elements together
2. Duplicates cancel: `x ^ x = 0`
3. Unique remains: `0 ^ x = x`
````

````col-md
**Code:**
```java
public int singleNumber(int[] nums) {
    int result = 0;
    for (int n : nums) result ^= n;
    return result;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Single element → itself
- Negative numbers → XOR works on bit representation

### 225. Single Number II — #137
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Bit counting — find element appearing once among triples** — for each bit position, sum all bits. Bit mod 3 = the unique element's bit.

`````col
````col-md
**Explanation:**
1. For each of 32 bit positions:
   - Count how many numbers have that bit set
   - If count % 3 != 0 → unique number has that bit
2. Reconstruct the unique number from bits
````

````col-md
**Code:**
```java
public int singleNumber(int[] nums) {
    int result = 0;
    for (int i = 0; i < 32; i++) {
        int sum = 0;
        for (int n : nums) sum += (n >> i) & 1;
        if (sum % 3 != 0) result |= (1 << i);
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(32n) = O(n) | Space: O(1)

**Edge Cases:**
- Negative unique number → works with two's complement
- All same (only one unique) → returns that element

### 226. Missing Number — #268
**Difficulty:** Easy

**Pattern & Key Insight:**
- **XOR with index-value pairs** — XOR 0..n with all elements. Every number cancels except the missing one.

`````col
````col-md
**Explanation:**
1. XOR all indices 0..n with all array elements
2. Every number appears twice (once in index, once in array) EXCEPT the missing one
3. Result = missing number
````

````col-md
**Code:**
```java
public int missingNumber(int[] nums) {
    int xor = nums.length;
    for (int i = 0; i < nums.length; i++) {
        xor ^= i ^ nums[i];
    }
    return xor;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Missing 0 → XOR of 1..n with all elements
- Missing n → all 0..n-1 present

### 227. Number of 1 Bits — #191
**Difficulty:** Easy

**Pattern & Key Insight:**
- **`n & (n-1)` clears the lowest set bit** — count how many times you can clear until n == 0. Each clear = one '1' bit.

`````col
````col-md
**Explanation:**
1. While n != 0:
   - `n = n & (n-1)` (clear lowest set bit)
   - Increment count
2. Return count
````

````col-md
**Code:**
```java
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);
        count++;
    }
    return count;
}
```
````
`````

**Complexity:** Time: O(number of 1 bits) | Space: O(1)

**Edge Cases:**
- n = 0 → 0 bits
- All bits set → 32

### 229. Reverse Bits — #190
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Extract and place bits** — extract bit i, place it at position 31-i. Build result one bit at a time.

`````col
````col-md
**Explanation:**
1. For each of 32 bits:
   - Extract lowest bit of n: `n & 1`
   - Shift result left, OR with extracted bit
   - Shift n right
2. After 32 iterations, result has reversed bits
````

````col-md
**Code:**
```java
public int reverseBits(int n) {
    int result = 0;
    for (int i = 0; i < 32; i++) {
        result = (result << 1) | (n & 1);
        n >>>= 1;
    }
    return result;
}
```
````
`````

**Complexity:** Time: O(32) = O(1) | Space: O(1)

**Edge Cases:**
- n = 0 → 0
- Use `>>>` (unsigned right shift) not `>>` in Java

### 230. Sum of Two Integers — #371
**Difficulty:** Medium

**Pattern & Key Insight:**
- **XOR for sum, AND+shift for carry** — `a^b` = sum without carry. `(a&b)<<1` = carry. Repeat until carry = 0.

`````col
````col-md
**Explanation:**
1. `sum = a ^ b` (add without carry)
2. `carry = (a & b) << 1` (carry bits shifted left)
3. Repeat with sum and carry until carry == 0
4. Return sum
````

````col-md
**Code:**
```java
public int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;
        a = a ^ b;
        b = carry;
    }
    return a;
}
```
````
`````

**Complexity:** Time: O(32) = O(1) | Space: O(1)

**Edge Cases:**
- Negative numbers → works with two's complement
- One operand is 0 → returns the other
- Both negative → carry propagation handles it
