### 170. Climbing Stairs — #70
**Difficulty:** Easy

**Pattern & Key Insight:**
- **Fibonacci DP (`dp[i] = dp[i-1] + dp[i-2]`)** — from step i, you could have come from i-1 or i-2. Space-optimize to two variables.

`````col
````col-md
**Explanation:**
1. Base: `dp[1] = 1`, `dp[2] = 2`
2. For i=3..n: `dp[i] = dp[i-1] + dp[i-2]`
3. Space-optimize: keep only prev two values
````

````col-md
**Code:**
```java
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- n = 1 → 1 way
- n = 2 → 2 ways

### 171. House Robber — #198
**Difficulty:** Medium

**Pattern & Key Insight:**
- **"Take or skip" decision DP** — `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. At each house: rob it (add to i-2) or skip (keep i-1).

`````col
````col-md
**Explanation:**
1. `prev2 = 0` (two back), `prev1 = 0` (one back)
2. For each house: `current = max(prev1, prev2 + nums[i])`
3. Shift: `prev2 = prev1`, `prev1 = current`
4. Return `prev1`
````

````col-md
**Code:**
```java
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int curr = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Single house → rob it
- Two houses → max of the two

### 172. House Robber II — #213
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Circular array DP — solve twice (exclude first OR last)** — can't rob both first and last. Solve on `[0..n-2]` and `[1..n-1]`, take max.

`````col
````col-md
**Explanation:**
1. If n == 1 → return nums[0]
2. Solve House Robber on `nums[0..n-2]`
3. Solve House Robber on `nums[1..n-1]`
4. Return max of both
````

````col-md
**Code:**
```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    return Math.max(robRange(nums, 0, nums.length - 2),
                    robRange(nums, 1, nums.length - 1));
}

private int robRange(int[] nums, int start, int end) {
    int prev2 = 0, prev1 = 0;
    for (int i = start; i <= end; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Single house → return it
- Two houses → max of both

### 173. Jump Game — #55
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Greedy — track max reachable index** — if at any point `i > maxReach`, we're stuck. Otherwise, update `maxReach = max(maxReach, i + nums[i])`.

`````col
````col-md
**Explanation:**
1. `maxReach = 0`
2. For each index `i`:
   - If `i > maxReach` → can't reach here → false
   - Update `maxReach = max(maxReach, i + nums[i])`
3. Return true
````

````col-md
**Code:**
```java
public boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    return true;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Single element → always true
- First element is 0 (and n > 1) → false
- Very large jumps → immediately reachable

### 174. Jump Game II — #45
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Greedy — BFS-like level jumps** — treat reachable ranges as BFS levels. `currentEnd` marks level boundary; when `i == currentEnd`, jump count++ and extend to `farthest`.

`````col
````col-md
**Explanation:**
1. `jumps = 0`, `currentEnd = 0`, `farthest = 0`
2. For each `i` (except last):
   - `farthest = max(farthest, i + nums[i])`
   - If `i == currentEnd`: jump++, `currentEnd = farthest`
3. Return jumps
````

````col-md
**Code:**
```java
public int jump(int[] nums) {
    int jumps = 0, currentEnd = 0, farthest = 0;
    for (int i = 0; i < nums.length - 1; i++) {
        farthest = Math.max(farthest, i + nums[i]);
        if (i == currentEnd) {
            jumps++;
            currentEnd = farthest;
        }
    }
    return jumps;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- Already at last index → 0 jumps
- Can reach end in 1 jump → 1

### 175. Word Break — #139
**Difficulty:** Medium

**Pattern & Key Insight:**
- **1D DP on string — `dp[i]` = can we segment s[0..i-1]** — for each position, check all possible word endings using a dictionary set.

`````col
````col-md
**Explanation:**
1. `dp[0] = true` (empty string)
2. For each `i` from 1 to n:
   - For each `j` from 0 to i-1:
     - If `dp[j]` is true AND `s[j..i-1]` is in dictionary → `dp[i] = true`
3. Return `dp[n]`
````

````col-md
**Code:**
```java
public boolean wordBreak(String s, List<String> wordDict) {
    Set<String> dict = new HashSet<>(wordDict);
    boolean[] dp = new boolean[s.length() + 1];
    dp[0] = true;
    for (int i = 1; i <= s.length(); i++) {
        for (int j = 0; j < i; j++) {
            if (dp[j] && dict.contains(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[s.length()];
}
```
````
`````

**Complexity:** Time: O(n² × m) where m = substring comparison | Space: O(n)

**Edge Cases:**
- Single word matches entire string → true
- No word matches start → false early
- Overlapping words in dictionary

### 176. Decode Ways — #91
**Difficulty:** Medium

**Pattern & Key Insight:**
- **1D DP with conditional transitions (handle '0' carefully)** — single digit (1-9) valid, two digits (10-26) valid. '0' alone is invalid.

`````col
````col-md
**Explanation:**
1. `dp[0] = 1` (empty), `dp[1] = s[0] != '0' ? 1 : 0`
2. For i = 2..n:
   - Single: if `s[i-1] != '0'` → `dp[i] += dp[i-1]`
   - Double: if `s[i-2..i-1]` is 10-26 → `dp[i] += dp[i-2]`
3. Return dp[n]
````

````col-md
**Code:**
```java
public int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1];
    dp[0] = 1;
    dp[1] = s.charAt(0) != '0' ? 1 : 0;
    for (int i = 2; i <= n; i++) {
        int one = s.charAt(i-1) - '0';
        int two = Integer.parseInt(s.substring(i-2, i));
        if (one >= 1) dp[i] += dp[i-1];
        if (two >= 10 && two <= 26) dp[i] += dp[i-2];
    }
    return dp[n];
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n) — can optimize to O(1)

**Edge Cases:**
- Starts with '0' → 0 ways
- Contains "00" → 0 ways
- "10", "20" → only valid as two-digit

### 177. Coin Change — #322
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Unbounded knapsack — minimize count** — `dp[i] = min(dp[i], dp[i-coin] + 1)`. Forward-fill: each amount tries all coins.

`````col
````col-md
**Explanation:**
1. `dp[0] = 0`, rest = `amount + 1` (impossible sentinel)
2. For each amount from 1 to target:
   - For each coin: if `coin <= amount`, `dp[amount] = min(dp[amount], dp[amount-coin] + 1)`
3. Return `dp[amount]` if ≤ amount, else -1
````

````col-md
**Code:**
```java
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```
````
`````

**Complexity:** Time: O(amount × coins) | Space: O(amount)

**Edge Cases:**
- amount = 0 → 0 coins
- No combination works → -1
- Single coin larger than amount → -1

### 178. Coin Change II — #518
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Unbounded knapsack — count ways** — outer loop = coins, inner loop = amounts. This ordering counts combinations (not permutations).

`````col
````col-md
**Explanation:**
1. `dp[0] = 1` (one way to make 0)
2. For each coin (outer):
   - For amount from coin to target (inner):
     - `dp[amount] += dp[amount - coin]`
3. Outer loop on coins ensures each combination counted once
````

````col-md
**Code:**
```java
public int change(int amount, int[] coins) {
    int[] dp = new int[amount + 1];
    dp[0] = 1;
    for (int coin : coins) {
        for (int i = coin; i <= amount; i++) {
            dp[i] += dp[i - coin];
        }
    }
    return dp[amount];
}
```
````
`````

**Complexity:** Time: O(amount × coins) | Space: O(amount)

**Edge Cases:**
- amount = 0 → 1 (empty combination)
- No coins → 0 ways (unless amount = 0)
- Single coin → 1 way if divisible, else 0

### 179. Counting Bits — #338
**Difficulty:** Easy

**Pattern & Key Insight:**
- **DP using bit relationship (`dp[i] = dp[i>>1] + (i&1)`)** — right-shift removes last bit; `i&1` checks if last bit is 1.

`````col
````col-md
**Explanation:**
1. `dp[0] = 0`
2. For i = 1..n: `dp[i] = dp[i >> 1] + (i & 1)`

````

````col-md

public int[] countBits(int n) {
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i >> 1] + (i & 1);
    }
    return dp;
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(n)

**Edge Cases:**
- n = 0 → [0]
- Powers of 2 → exactly 1 bit

### 180. Longest Increasing Subsequence — #300
**Difficulty:** Medium

**Pattern & Key Insight:**
- **O(n log n) patience sorting** — maintain a `tails` array where `tails[i]` = smallest ending element of all increasing subsequences of length `i+1`. Binary search to find position.

`````col
````col-md
**Explanation:**
1. `tails[]` array (dynamic)
2. For each num:
   - Binary search for leftmost position in tails where `tails[pos] >= num`
   - If pos == tails.size → append (extends LIS)
   - Else → replace tails[pos] (maintain smallest tail)
3. tails.size = LIS length
````

````col-md
**Code:**
```java
public int lengthOfLIS(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    for (int num : nums) {
        int pos = Collections.binarySearch(tails, num);
        if (pos < 0) pos = -(pos + 1);
        if (pos == tails.size()) tails.add(num);
        else tails.set(pos, num);
    }
    return tails.size();
}
```
````
`````

**Complexity:** Time: O(n log n) | Space: O(n)

**Edge Cases:**
- All same → LIS = 1
- Already sorted → LIS = n
- Strictly decreasing → LIS = 1

### 181. Partition Equal Subset Sum — #416
**Difficulty:** Medium

**Pattern & Key Insight:**
- **0/1 knapsack — boolean subset sum** — can we form `totalSum/2`? `dp[j] = dp[j] || dp[j-nums[i]]`. Iterate j BACKWARDS to avoid reusing elements.

`````col
````col-md
**Explanation:**
1. If total sum is odd → false
2. Target = sum / 2
3. `dp[0] = true`
4. For each num (outer), for j from target down to num (inner):
   - `dp[j] = dp[j] || dp[j - num]`
5. Return dp[target]
````

````col-md
**Code:**
```java
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int n : nums) sum += n;
    if (sum % 2 != 0) return false;
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int num : nums) {
        for (int j = target; j >= num; j--) {
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
```
````
`````

**Complexity:** Time: O(n × sum) | Space: O(sum)

**Edge Cases:**
- Odd total sum → immediately false
- Single element → false (can't partition)
- Element equals target → true

### 182. Best Time to Buy and Sell Stock with Cooldown — #309
**Difficulty:** Medium

**Pattern & Key Insight:**
- **State-machine DP (hold / sold / rest states)** — three states: holding stock, just sold (cooldown next), resting. Transitions model the constraints.

`````col
````col-md
**Explanation:**
1. `hold` = max profit while holding stock
2. `sold` = max profit on day we just sold
3. `rest` = max profit while resting (can buy tomorrow)
4. Transitions:
   - `hold = max(hold, rest - price)`
   - `sold = hold + price`
   - `rest = max(rest, sold)`
````

````col-md
**Code:**
```java
public int maxProfit(int[] prices) {
    int hold = Integer.MIN_VALUE, sold = 0, rest = 0;
    for (int price : prices) {
        int prevSold = sold;
        sold = hold + price;
        hold = Math.max(hold, rest - price);
        rest = Math.max(rest, prevSold);
    }
    return Math.max(sold, rest);
}
```
````
`````

**Complexity:** Time: O(n) | Space: O(1)

**Edge Cases:**
- 1-2 days → standard buy-sell or no transaction
- All decreasing → profit = 0

### 183. Best Time to Buy and Sell Stock IV — #188
**Difficulty:** Hard

**Pattern & Key Insight:**
- **State-machine DP with k transactions** — `dp[t][0]` = max profit with t transactions not holding; `dp[t][1]` = holding. When k ≥ n/2, reduce to unlimited (greedy).

`````col
````col-md
**Explanation:**
1. If `k >= n/2` → unlimited transactions (greedy sum of all gains)
2. Else: `dp[t][0]` and `dp[t][1]` for each transaction count
3. For each price:
   - `dp[t][0] = max(dp[t][0], dp[t][1] + price)` (sell)
   - `dp[t][1] = max(dp[t][1], dp[t-1][0] - price)` (buy)
4. Return `dp[k][0]`
````

````col-md
**Code:**
```java
public int maxProfit(int k, int[] prices) {
    int n = prices.length;
    if (k >= n / 2) {
        int profit = 0;
        for (int i = 1; i < n; i++) profit += Math.max(0, prices[i] - prices[i-1]);
        return profit;
    }
    int[][] dp = new int[k + 1][2];
    for (int t = 0; t <= k; t++) dp[t][1] = Integer.MIN_VALUE;
    for (int price : prices) {
        for (int t = k; t >= 1; t--) {
            dp[t][0] = Math.max(dp[t][0], dp[t][1] + price);
            dp[t][1] = Math.max(dp[t][1], dp[t-1][0] - price);
        }
    }
    return dp[k][0];
}
```
````
`````

**Complexity:** Time: O(n × k) | Space: O(k)

**Edge Cases:**
- k = 0 → 0 profit
- k = 1 → standard single transaction
- k >= n/2 → greedy unlimited

### 184. Longest Increasing Path in a Matrix — #329
**Difficulty:** Hard

**Pattern & Key Insight:**
- **DFS + memoization on 2D grid (DAG DP)** — each cell's longest path depends on neighbors with smaller values (forming a DAG). Memo avoids recomputation.

`````col
````col-md
**Explanation:**
1. For each cell, DFS to find longest increasing path starting there
2. Only move to neighbors with strictly greater values
3. Memoize: `memo[r][c]` = longest path from (r,c)
4. Return max across all cells
````

````col-md
**Code:**
```java
int[][] memo;
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

public int longestIncreasingPath(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    memo = new int[m][n];
    int max = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            max = Math.max(max, dfs(matrix, i, j));
    return max;
}

private int dfs(int[][] matrix, int r, int c) {
    if (memo[r][c] != 0) return memo[r][c];
    int longest = 1;
    for (int[] d : dirs) {
        int nr = r+d[0], nc = c+d[1];
        if (nr >= 0 && nr < matrix.length && nc >= 0 && nc < matrix[0].length
            && matrix[nr][nc] > matrix[r][c]) {
            longest = Math.max(longest, 1 + dfs(matrix, nr, nc));
        }
    }
    return memo[r][c] = longest;
}
```
````
`````

**Complexity:** Time: O(m × n) | Space: O(m × n)

**Edge Cases:**
- 1×1 matrix → 1
- All same values → 1 (no increasing path)
- Strictly increasing row → path = n

### 185. Unique Paths — #62
**Difficulty:** Medium

**Pattern & Key Insight:**
- **2D DP grid — count paths** — `dp[i][j] = dp[i-1][j] + dp[i][j-1]`. Can only move right or down. Space-optimize to 1D array.

`````col
````col-md
**Explanation:**
1. First row and first column all 1s (only one way to reach)
2. For each cell: sum of cell above + cell to left
3. Return dp[m-1][n-1]
````

````col-md
**Code:**
```java
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[j] += dp[j - 1];
    return dp[n - 1];
}
```
````
`````

**Complexity:** Time: O(m × n) | Space: O(n)

**Edge Cases:**
- 1×1 grid → 1
- 1×n or m×1 → 1 (only one path)

### 186. Minimum Path Sum — #64
**Difficulty:** Medium

**Pattern & Key Insight:**
- **2D DP grid — minimize cost** — `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`. Same structure as #62 but with minimization.

`````col
````col-md
**Explanation:**
1. First row: cumulative sum left to right
2. First col: cumulative sum top to bottom
3. Each cell: `grid[i][j] + min(above, left)`
4. Return dp[m-1][n-1]
````

````col-md
**Code:**
```java
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    for (int i = 1; i < m; i++) grid[i][0] += grid[i-1][0];
    for (int j = 1; j < n; j++) grid[0][j] += grid[0][j-1];
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            grid[i][j] += Math.min(grid[i-1][j], grid[i][j-1]);
    return grid[m-1][n-1];
}
```
````
`````

**Complexity:** Time: O(m × n) | Space: O(1) (modify in-place)

**Edge Cases:**
- 1×1 → return grid[0][0]
- Single row/column → sum of all elements

### 188. Longest Common Subsequence — #1143
**Difficulty:** Medium

**Pattern & Key Insight:**
- **2D DP on two sequences** — if chars match: `dp[i][j] = dp[i-1][j-1] + 1`. Else: `max(dp[i-1][j], dp[i][j-1])`.

`````col
````col-md
**Explanation:**
1. dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]
2. If `s1[i-1] == s2[j-1]`: extend diagonal `dp[i-1][j-1] + 1`
3. Else: take max(skip s1 char, skip s2 char)
4. Return dp[m][n]
````

````col-md
**Code:**
```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i-1) == text2.charAt(j-1))
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
        }
    return dp[m][n];
}
```
````
`````

**Complexity:** Time: O(m × n) | Space: O(m × n) — can optimize to O(n)

**Edge Cases:**
- One string empty → 0
- Identical strings → LCS = length
- No common characters → 0

### 189. Edit Distance — #72
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Levenshtein distance DP (insert/delete/replace)** — three-way recurrence: `dp[i][j] = min(insert, delete, replace)`. If chars match, carry diagonal.

`````col
````col-md
**Explanation:**
1. dp[i][j] = min ops to convert word1[0..i-1] to word2[0..j-1]
2. Base: dp[i][0] = i (delete all), dp[0][j] = j (insert all)
3. If chars match: dp[i][j] = dp[i-1][j-1]
4. Else: 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
````

````col-md
**Code:**
```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
`````

`````col
public boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();

        if (p.charAt(j-1) == '*') dp[0][j] = dp[0][j-2];
`````

### 197. Minimum Cost Tree From Leaf Values — #1130
**Difficulty:** Medium

**Pattern & Key Insight:**
- **Interval DP or monotonic stack** — interval DP: dp[i][j] = min cost to build subtree from leaves [i,j]. Greedy/stack: remove smallest leaf, cost = product with smaller neighbor.

`````col
````col-md
**Explanation:**
Stack (greedy) approach:
1. Maintain monotonic decreasing stack
2. When current > stack top: pop, cost += popped × min(stack.peek(), current)
3. This greedily pairs smallest leaves with their smallest neighbors
````

````col-md
**Code:**
```java
public int mctFromLeafValues(int[] arr) {
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(Integer.MAX_VALUE);
    int cost = 0;
    for (int val : arr) {
        while (stack.peek() <= val) {
            int mid = stack.pop();
            cost += mid * Math.min(stack.peek(), val);
        }
        stack.push(val);
    }
    while (stack.size() > 2) {
        cost += stack.pop() * stack.peek();
    }
    return cost;
}
```
`````

**Complexity:** Time: O(n) with stack | Space: O(n)

**Edge Cases:**
- Two elements → single product
- Sorted ascending → stack pops on each new element

### 198. Burst Balloons — #312
**Difficulty:** Hard

**Pattern & Key Insight:**
- **Interval DP — think about which balloon to pop LAST** — instead of first, think last in range [i,j]. The last-popped balloon's neighbors are the boundaries (i-1, j+1). Counterintuitive but correct.

`````col
````col-md
**Explanation:**
1. Add virtual balloons 1 at boundaries: [1, ...nums..., 1]
2. dp[i][j] = max coins from popping all balloons in (i, j) exclusive
3. For each k in (i+1, j-1) as last balloon to pop:
   - dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])
4. Fill by interval length (small → large)
````

````col-md
**Code:**
```java
public int maxCoins(int[] nums) {
    int n = nums.length;
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    for (int i = 0; i < n; i++) arr[i + 1] = nums[i];

    int[][] dp = new int[n + 2][n + 2];
    for (int len = 2; len <= n + 1; len++) {
        for (int i = 0; i + len <= n + 1; i++) {
            int j = i + len;
            for (int k = i + 1; k < j; k++) {
                dp[i][j] = Math.max(dp[i][j],
                    dp[i][k] + dp[k][j] + arr[i] * arr[k] * arr[j]);
            }
        }
    }
    return dp[0][n + 1];
}
```
`````

**Edge Cases:**
- Single balloon → just its value (bounded by virtual 1s)
- Two balloons → pop smaller first (or compute both orders)
- All same values → order doesn't matter for value but matters for cost

**Difficulty:** Medium

**Pattern & Key Insight:**
- **2D 0/1 Knapsack (two constraints: count of 0s and 1s)** — dp[i][j] = max strings using at most i zeros and j ones. Two capacity dimensions.

`````col
public int findMaxForm(String[] strs, int m, int n) {

    for (String s : strs) {
        int zeros = (int) s.chars().filter(c -> c == '0').count();
        int ones = s.length() - zeros;
`````

### 205. Cherry Pickup II — #1463
**Difficulty:** Hard

**Pattern & Key Insight:**
- **3D DP — two agents on a grid simultaneously** — two robots start at top-left and top-right, move down. dp[row][col1][col2] = max cherries collected.

`````col
````col-md
**Explanation:**
1. dp[r][c1][c2] = max cherries when robot1 at (r,c1), robot2 at (r,c2)
2. Both move down one row, each can go to col-1, col, col+1
3. If c1 == c2 → count cell once (avoid double-counting)
4. 9 combinations per cell pair per row
5. Fill bottom-up (from last row to first)
````

````col-md
**Code:**
```java
public int cherryPickup(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][][] dp = new int[m][n][n];
    for (int[][] layer : dp) for (int[] row : layer) Arrays.fill(row, -1);
    dp[0][0][n-1] = grid[0][0] + grid[0][n-1];

    for (int r = 1; r < m; r++)
        for (int c1 = 0; c1 < n; c1++)
            for (int c2 = 0; c2 < n; c2++) {
                int cherries = c1 == c2 ? grid[r][c1] : grid[r][c1] + grid[r][c2];
                int best = -1;
                for (int dc1 = -1; dc1 <= 1; dc1++)
                    for (int dc2 = -1; dc2 <= 1; dc2++) {
                        int pc1 = c1 - dc1, pc2 = c2 - dc2;
                        if (pc1 >= 0 && pc1 < n && pc2 >= 0 && pc2 < n && dp[r-1][pc1][pc2] >= 0)
                            best = Math.max(best, dp[r-1][pc1][pc2]);
                    }
                if (best >= 0) dp[r][c1][c2] = best + cherries;
            }

    int max = 0;
    for (int c1 = 0; c1 < n; c1++)
        for (int c2 = 0; c2 < n; c2++)
            max = Math.max(max, dp[m-1][c1][c2]);
    return max;
}
```
````
`````

**Complexity:** Time: O(m × n² × 9) | Space: O(m × n²)

**Edge Cases:**
- Single column → both robots in same cell every row
- Wide grid → robots can spread far apart
- All zeros except edges → robots stay at edges
