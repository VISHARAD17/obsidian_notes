In Java, the `.stream()` method is used to create a stream from a collection, array, or other data source, enabling functional-style operations on the data. Below is a comprehensive list of common functionalities (methods) that can be used with `.stream()` in Java, focusing on intermediate and terminal operations, along with examples like `mapToInt().summaryStatistics()`. I'll categorize them for clarity and include the example you provided.

### Overview of Stream Operations
Stream operations are divided into:
- **Intermediate Operations**: Transform or filter the stream and return a new stream (lazy evaluation).
- **Terminal Operations**: Produce a result or side-effect, closing the stream.
- **Short-Circuit Operations**: Can terminate the stream pipeline early.

### 1. Intermediate Operations
These operations transform or filter the stream and can be chained.

- `filter(Predicate<T> predicate)`: Keeps elements that match the predicate.
  ```java
  List<Integer> numbers = List.of(1, 2, 3, 4);
  numbers.stream().filter(n -> n % 2 == 0).forEach(System.out::println); // Prints 2, 4
  ```

- **`map(Function<T, R> mapper)`**: Transforms each element into another type.
  ```java
  List<String> names = List.of("Alice", "Bob");
  names.stream().map(String::toUpperCase).forEach(System.out::println); // Prints ALICE, BOB
  ```

- **`mapToInt(ToIntFunction<T> mapper)`**: Maps elements to an `IntStream`.
  ```java
  List<String> lengths = List.of("one", "two");
  lengths.stream().mapToInt(String::length).forEach(System.out::println); // Prints 3, 3
  ```

- **`mapToLong(ToLongFunction<T> mapper)`**: Maps elements to a `LongStream`.
  ```java
  List<String> lengths = List.of("one", "two");
  lengths.stream().mapToLong(String::length).forEach(System.out::println); // Prints 3, 3
  ```

- `mapToDouble(ToDoubleFunction<T> mapper)`: Maps elements to a `DoubleStream`.
  ```java
  List<String> lengths = List.of("one", "two");
  lengths.stream().mapToDouble(String::length).forEach(System.out::println); // Prints 3.0, 3.0
  ```

- `flatMap(Function<T, Stream<R>> mapper)`: Flattens nested streams into a single stream.
  ```java
  List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3, 4));
  nested.stream().flatMap(List::stream).forEach(System.out::println); // Prints 1, 2, 3, 4
  ```

- **`flatMapToInt(Function<T, IntStream> mapper)`**: Flattens into an `IntStream`.
  ```java
  List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3, 4));
  nested.stream().flatMapToInt(list -> list.stream().mapToInt(i -> i)).forEach(System.out::println);
  ```

- `flatMapToLong(Function<T, LongStream> mapper)`: Flattens into a `LongStream`.
- `flatMapToDouble(Function<T, DoubleStream> mapper)`: Flattens into a `DoubleStream`.

- `distinct()`: Removes duplicates based on `equals()`.
  ```java
  List<Integer> numbers = List.of(1, 2, 2, 3);
  numbers.stream().distinct().forEach(System.out::println); // Prints 1, 2, 3
  ```

- `sorted()`: Sorts elements in natural order.
  ```java
  List<Integer> numbers = List.of(3, 1, 2);
  numbers.stream().sorted().forEach(System.out::println); // Prints 1, 2, 3
  ```

- `sorted(Comparator<T> comparator)`: Sorts elements using a custom comparator.
  ```java
  List<String> names = List.of("Bob", "Alice");
  names.stream().sorted(Comparator.reverseOrder()).forEach(System.out::println); // Prints Bob, Alice
  ```

- `peek(Consumer<T> action)`: Performs an action on each element for debugging or side effects.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  numbers.stream().peek(n -> System.out.println("Processing: " + n)).map(n -> n * 2).forEach(System.out::println);
  ```

- **`limit(long maxSize)`**: Restricts the stream to the first `maxSize` elements.
  ```java
  List<Integer> numbers = List.of(1, 2, 3, 4);
  numbers.stream().limit(2).forEach(System.out::println); // Prints 1, 2
  ```

- **`skip(long n)`**: Skips the first `n` elements.
  ```java
  List<Integer> numbers = List.of(1, 2, 3, 4);
  numbers.stream().skip(2).forEach(System.out::println); // Prints 3, 4
  ```

- **`takeWhile(Predicate<T> predicate)`**: Takes elements while the predicate is true (Java 9+).
  ```java
  List<Integer> numbers = List.of(1, 2, 3, 0, 4);
  numbers.stream().takeWhile(n -> n < 3).forEach(System.out::println); // Prints 1, 2
  ```

- **`dropWhile(Predicate<T> predicate)`**: Drops elements while the predicate is true (Java 9+).
  ```java
  List<Integer> numbers = List.of(1, 2, 3, 0, 4);
  numbers.stream().dropWhile(n -> n < 3).forEach(System.out::println); // Prints 3, 0, 4
  ```

### **2. Terminal Operations**
These operations produce a result or side-effect and close the stream.

- **`forEach(Consumer<T> action)`**: Performs an action for each element.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  numbers.stream().forEach(System.out::println); // Prints 1, 2, 3
  ```

- **`forEachOrdered(Consumer<T> action)`**: Performs an action for each element in encounter order (useful for parallel streams).
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  numbers.stream().parallel().forEachOrdered(System.out::println); // Prints 1, 2, 3
  ```

- **`toArray()`**: Converts the stream to an array.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Integer[] array = numbers.stream().toArray(Integer[]::new);
  ```

- **`toArray(IntFunction<A[]> generator)`**: Converts to a specific array type.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Integer[] array = numbers.stream().toArray(Integer[]::new);
  ```

- **`reduce(T identity, BinaryOperator<T> accumulator)`**: Reduces the stream to a single value with an initial value.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  int sum = numbers.stream().reduce(0, Integer::sum); // Returns 6
  ```

- **`reduce(BinaryOperator<T> accumulator)`**: Reduces without an initial value, returning an `Optional`.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Optional<Integer> sum = numbers.stream().reduce(Integer::sum); // Returns Optional[6]
  ```

- **`collect(Collector<T, A, R> collector)`**: Collects elements into a collection or other result.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  List<Integer> list = numbers.stream().collect(Collectors.toList());
  ```

- **`collect(Supplier<R> supplier, BiConsumer<R, T> accumulator, BiConsumer<R, R> combiner)`**: Custom collection.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  StringBuilder sb = numbers.stream().collect(StringBuilder::new, (sb, n) -> sb.append(n), StringBuilder::append);
  ```

- **`min(Comparator<T> comparator)`**: Finds the minimum element.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Optional<Integer> min = numbers.stream().min(Integer::compareTo); // Returns Optional[1]
  ```

- **`max(Comparator<T> comparator)`**: Finds the maximum element.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Optional<Integer> max = numbers.stream().max(Integer::compareTo); // Returns Optional[3]
  ```

- **`count()`**: Counts the number of elements.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  long count = numbers.stream().count(); // Returns 3
  ```

- **`anyMatch(Predicate<T> predicate)`**: Returns true if any element matches.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  boolean hasEven = numbers.stream().anyMatch(n -> n % 2 == 0); // Returns true
  ```

- **`allMatch(Predicate<T> predicate)`**: Returns true if all elements match.
  ```java
  List<Integer> numbers = List.of(2, 4, 6);
  boolean allEven = numbers.stream().allMatch(n -> n % 2 == 0); // Returns true
  ```

- **`noneMatch(Predicate<T> predicate)`**: Returns true if no elements match.
  ```java
  List<Integer> numbers = List.of(1, 3, 5);
  boolean noEven = numbers.stream().noneMatch(n -> n % 2 == 0); // Returns true
  ```

- **`findFirst()`**: Returns the first element as an `Optional`.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Optional<Integer> first = numbers.stream().findFirst(); // Returns Optional[1]
  ```

- **`findAny()`**: Returns any element as an `Optional` (useful in parallel streams).
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  Optional<Integer> any = numbers.stream().findAny(); // Returns Optional[some element]
  ```

### **3. Primitive Stream Operations (e.g., `IntStream`, `LongStream`, `DoubleStream`)**
When using `mapToInt()`, `mapToLong()`, or `mapToDouble()`, you get a primitive stream with additional specialized methods.

- **`sum()`**: Returns the sum of elements.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  int sum = numbers.stream().mapToInt(i -> i).sum(); // Returns 6
  ```

- **`average()`**: Returns the average as an `OptionalDouble`.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  OptionalDouble avg = numbers.stream().mapToInt(i -> i).average(); // Returns OptionalDouble[2.0]
  ```

- **`summaryStatistics()`**: Provides summary statistics (count, sum, min, max, average).
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  IntSummaryStatistics stats = numbers.stream().mapToInt(i -> i).summaryStatistics();
  System.out.println(stats); // Prints {count=3, sum=6, min=1, average=2.0, max=3}
  ```

- **`boxed()`**: Converts a primitive stream back to a `Stream<T>`.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  List<Integer> boxed = numbers.stream().mapToInt(i -> i).boxed().collect(Collectors.toList());
  ```

### **4. Short-Circuit Operations**
These operations can terminate the stream early, improving performance.

- **`anyMatch(Predicate<T> predicate)`**, **`allMatch(Predicate<T> predicate)`**, **`noneMatch(Predicate<T> predicate)`**, **`findFirst()`**, **`findAny()`**: Already listed above.
- **`limit(long maxSize)`**, **`takeWhile(Predicate<T> predicate)`**: Also listed above.

### 5. Parallel Stream Operations
Streams can be made parallel using `.parallel()` or by calling `.parallelStream()` on a collection.

- **`parallel()`**: Converts a stream to parallel mode.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  numbers.stream().parallel().forEach(System.out::println); // Order not guaranteed
  ```

- **`sequential()`**: Converts a parallel stream back to sequential.
  ```java
  List<Integer> numbers = List.of(1, 2, 3);
  numbers.stream().parallel().sequential().forEach(System.out::println);
  ```

### 7. Collectors (Used with `collect()`)
The `collect()` method often uses `Collectors` for common operations:
- `toList()`: Collects to a `List`.
- `toSet()`: Collects to a `Set`.
- `toMap(Function keyMapper, Function valueMapper)`: Collects to a `Map`.
- `joining()`: Concatenates strings.
- `groupingBy(Function classifier)`: Groups elements.
- `partitioningBy(Predicate predicate)`: Partitions into true/false groups.
  ```java
  List<String> names = List.of("Alice", "Bob", "Charlie");
  String joined = names.stream().collect(Collectors.joining(", ")); // Returns "Alice, Bob, Charlie"
  ```

### Notes
- **Chaining**: Most intermediate operations can be chained (e.g., `filter().map().sorted()`).
- **Lazy Evaluation**: Intermediate operations are lazy; they execute only when a terminal operation is called.
- **Stateless vs. Stateful**: Operations like `filter()` and `map()` are stateless; `sorted()` and `distinct()` are stateful, requiring more memory.
- **Primitive Streams**: Use `IntStream`, `LongStream`, or `DoubleStream` for better performance with primitives.
- **Parallel Streams**: Use `parallel()` cautiously, as it may not always improve performance and can introduce complexity.
