While designing system we need to make decisions about which features to include and while to ignore, creating tradeoffs

##### 1. Scalability vs Performance
- scalability is about size and performance is about speed
- ex. Adding more machines to a system to make it more scalable, will affect its performance, due to managing multiple machines and co-ordinating tasks across, in service communication.
