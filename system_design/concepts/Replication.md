> Replication means keeping a copy of the same data on multiple machines that are connected via network

- to keep data geographically closer to the users **reduce latency**
- Allows system to continue working even if some of its parts failed **increase availability**
- Scales out the number of machine that can server read queries **increase read through**

**3 Replication types** :
- single leader
- multi-leader
- leaderless*
