> A computer network is formed by two or more devices connected together. 
> Almost all the devices are connected to the biggest network **Internet**
##### **Key challenges computer networks**:
1. **Reliability** : Make sure each request reaches the server reliably doesn't get lost.
2. **Scalability** : networks has been growing a lot. Need to ensure that all the devices are properly connected and all the devices get a proper IP address and no address collision.
3. **Allocation of bandwidth**: ensure that no one subnet is consuming all the resources and not allowing others to use it.
4. **Security** : send and receive data/request securely
