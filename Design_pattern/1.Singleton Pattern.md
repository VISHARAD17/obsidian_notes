#creationalPattern

Singleton pattern is used to create a only one instance through out the program
- declare a `private static instance` so to not have to create a new instance by creating an object
```java
public class SingletonClass{
	private static SingletonClass instance;
	int val;
	private SingletonClass{
		val = 0;
	}

	public SingletonClass getInstance(){
		if(instance == null){
			new SingletonClass();	
		}
		return instance;
	}

	public getVal(){
		return val;	
	}
}
```

call in main class
```java
public static void main(String[] args){
	SingletonClass singletonClass = SingletonClass.getInstance();
	System.out.println("val is ", singletonClass.getVal()); // val is 0
}
```
